0写在前面：三角函数的三条主线

三角函数公式多，但如果你知道它们都从哪来，就不需要背几十条公式了。

这一章被很多同学称为"公式地狱"——诱导公式十几条、和差角公式六条、二倍角公式三条、降幂公式两条……加起来几十条。硬背的结果通常是：考场上记混，或者记对了但符号搞错。

但实际上，这一章真正需要"记住"的东西只有一个：单位圆。

主线一：从单位圆长出定义 角 \(\alpha\) 的终边与单位圆交于点 \(P(x,y)\)，规定 \(\sin\alpha=y\)、\(\cos\alpha=x\)。所有三角函数的性质都从这个定义来。
主线二：从单位圆长出公式 对称性 → 诱导公式；两点距离 → 和差角公式；和角公式令 \(\beta=\alpha\) → 二倍角公式。一条推导链，全部打通。
主线三：从定义长出图象 把 \(\sin\alpha\) 看成角变化时 \(P\) 点纵坐标的变化 → 正弦曲线。图象与性质是同一件事的两种说法。
学法建议
  1. 先画单位圆，再记公式。第 3 章（诱导公式）和第 5 章（恒等变换）的推导都只用单位圆，自己动手推一遍，公式量立刻从"几十条"降到"一个圆"。
  2. "奇变偶不变，符号看象限"要理解，不要背。第 3.2 节会逐字拆解这句口诀的含义。
  3. 第 4.3 节的图象变换是本章头号易错点。"先伸缩后平移"时平移量要除以 \(\omega\)，这一点必须彻底搞懂。
先建立两个重要直觉
  • 三角函数是"描述转圈"的函数。角转一圈回到原点，函数值就重复一次——这就是"周期性"的来源。
  • \(\sin\) 和 \(\cos\) 永远在 \([-1,1]\) 之间。因为 \(P\) 点在单位圆上，坐标 \(x,y\) 的绝对值都不会超过半径 1。

1角的概念与弧度制

这一章是"准备工作"。重点是弧度制的换算和两个公式（弧长、扇形面积）。

1.1　任意角

定义

一条射线绕它的端点旋转所形成的图形叫做角。规定：

  • 按逆时针方向旋转形成的角叫正角；
  • 按顺时针方向旋转形成的角叫负角；
  • 不做任何旋转形成的角叫零角（\(0^\circ\)）。

这样定义的角，取值范围可以是任意实数，所以叫任意角。

为什么要把角推广到任意大小？因为转圈可以转很多圈：转一整圈是 \(360^\circ\)，转两圈是 \(720^\circ\)，反过来转半圈是 \(-180^\circ\)。物理里（比如齿轮、电机）确实会遇到这些角，所以必须推广。

1.2　终边相同的角

定义

所有与角 \(\alpha\) 终边相同的角，连同 \(\alpha\) 在内，构成一个集合：

\[ S = \{\,\beta \mid \beta = \alpha + k\cdot360^\circ,\ k\in\mathbb{Z}\,\} \]

用弧度制写就是：

\[ S = \{\,\beta \mid \beta = \alpha + 2k\pi,\ k\in\mathbb{Z}\,\} \]
为什么是 \(k\cdot360^\circ\)

从 \(\alpha\) 的终边出发，再转一整圈（\(360^\circ\)），终边回到原来的位置。转两圈、三圈、或者反着转一圈（\(-360^\circ\)），终边都一样。

所以只要在 \(\alpha\) 的基础上加任意整数个 \(360^\circ\)，终边位置就不变。终边相同 ≠ 角相等，它们可以相差 \(360^\circ\) 的整数倍。

例题 1

把 \(-1050^\circ\) 写成 \(\alpha + k\cdot360^\circ\)（\(0^\circ\le\alpha<360^\circ\)，\(k\in\mathbb{Z}\)）的形式，并指出它是第几象限角。

解析

思路：反复加 \(360^\circ\)，直到结果落在 \([0^\circ,360^\circ)\) 内。

\[ -1050^\circ + 360^\circ = -690^\circ \]
\[ -690^\circ + 360^\circ = -330^\circ \]
\[ -330^\circ + 360^\circ = 30^\circ \]

所以一共加了 \(3\) 个 \(360^\circ\)：

\[ -1050^\circ = 30^\circ + (-3)\times 360^\circ \]

即 \(\alpha=30^\circ\)，\(k=-3\)。

因为 \(0^\circ<30^\circ<90^\circ\)，所以 \(-1050^\circ\) 是第一象限角。

验算（更快的方法）：直接算 \(-1050 \div 360 = -2.9166\dots\)，取整得 \(k=-3\)，则

\[ \alpha = -1050^\circ - (-3)\times360^\circ = -1050^\circ+1080^\circ = 30^\circ \quad\checkmark \]

1.3　弧度制

定义

长度等于半径的圆弧所对的圆心角叫做 1 弧度的角，记作 \(1\,\text{rad}\)（通常省略"rad"不写）。用弧度作为单位来度量角的制度叫做弧度制。

推导：为什么 \(180^\circ=\pi\) 弧度

第一步：算一个整圆（周角）是多少弧度。

半径为 \(r\) 的圆，周长是 \(C=2\pi r\)。用"弧长 ÷ 半径"来度量这个周角：

\[ \text{周角的弧度数} = \frac{\text{弧长}}{\text{半径}} = \frac{2\pi r}{r} = 2\pi \]

第二步：周角用角度制表示是 \(360^\circ\)。两种制度描述的是同一个角，所以：

\[ 360^\circ = 2\pi\ \text{rad} \]

第三步：两边同除以 2。

\[ \boxed{\ 180^\circ = \pi\ \text{rad}\ } \]

由此得到两个换算关系：

\[ 1^\circ = \frac{\pi}{180}\ \text{rad}\approx0.01745\ \text{rad},\qquad 1\ \text{rad}=\frac{180^\circ}{\pi}\approx57.30^\circ \]
换算技巧：抓住"\(180^\circ\leftrightarrow\pi\)"这一对

不需要记上面两个小公式，只要记住 \(180^\circ\) 对应 \(\pi\)，然后用比例算：

  • 角度 → 弧度：乘以 \(\dfrac{\pi}{180^\circ}\)。例如 \(60^\circ=60\times\dfrac{\pi}{180}=\dfrac{\pi}{3}\)。
  • 弧度 → 角度：乘以 \(\dfrac{180^\circ}{\pi}\)。例如 \(\dfrac{\pi}{4}=\dfrac{\pi}{4}\times\dfrac{180^\circ}{\pi}=45^\circ\)。

常用对应要背熟：

\[ 30^\circ=\frac{\pi}{6},\quad 45^\circ=\frac{\pi}{4},\quad 60^\circ=\frac{\pi}{3},\quad 90^\circ=\frac{\pi}{2},\quad 120^\circ=\frac{2\pi}{3},\quad 180^\circ=\pi,\quad 270^\circ=\frac{3\pi}{2},\quad 360^\circ=2\pi \]
弧度制下写角的三个习惯
  • 弧度单位通常省略不写：写 \(\dfrac{\pi}{3}\)，不写 \(\dfrac{\pi}{3}\ \text{rad}\)。
  • 用弧度制时，角是一个实数，所以可以参与运算（比如 \(2\pi+3\) 是有意义的）。这是弧度制最大的好处——把三角函数变成实数的函数。
  • 同一个式子里不要混用两种制度。写 \(\alpha=\dfrac{\pi}{6}+k\cdot360^\circ\) 是错的。

1.4　弧长公式与扇形面积公式

两个必记公式（其中 \(\alpha\) 必须用弧度制） \[ l = |\alpha|\,r \qquad\qquad S = \frac12 lr = \frac12|\alpha|r^{2} \]
推导一：弧长公式 \(l=|\alpha|r\)

用比例关系。圆心角为 \(\alpha\) 的弧长 \(l\)，与整个圆的关系是"角占多少比例，弧长就占多少比例"：

\[ \frac{l}{2\pi r} = \frac{\alpha}{2\pi} \]

左边是"弧长占周长的比例"，右边是"圆心角占周角的比例"，两者相等。

两边同乘 \(2\pi r\)：

\[ l = \frac{\alpha}{2\pi}\cdot 2\pi r = \alpha r \]

如果 \(\alpha\) 是负角（顺时针转），弧长取正值，所以加绝对值：\(l=|\alpha|r\)。∎

推导二：扇形面积公式 \(S=\dfrac12 lr=\dfrac12|\alpha|r^{2}\)

同样用比例关系。扇形面积占整个圆面积的比例，等于圆心角占周角的比例：

\[ \frac{S}{\pi r^{2}} = \frac{\alpha}{2\pi} \]

两边同乘 \(\pi r^2\)：

\[ S = \frac{\alpha}{2\pi}\cdot\pi r^{2} = \frac{1}{2}\alpha r^{2} \]

再把 \(l=\alpha r\) 代入，即 \(\alpha r=l\)，得到另一个形式：

\[ S = \frac12(\alpha r)\cdot r = \frac12 lr \quad\checkmark \]

对比记忆：三角形面积公式是 \(S=\dfrac12\times\text{底}\times\text{高}\)，扇形面积是 \(S=\dfrac12\times\text{弧长}\times\text{半径}\)——结构完全一样，把"底"换成"弧长"、"高"换成"半径"。

例题 2

已知扇形的圆心角为 \(\dfrac{2\pi}{3}\)，半径为 6。求扇形的弧长和面积。

解析

弧长：

\[ l = |\alpha|r = \frac{2\pi}{3}\times 6 = 4\pi \]

面积（用两个公式分别算，互相验证）：

\[ S = \frac12|\alpha|r^{2} = \frac12\times\frac{2\pi}{3}\times36 = \frac12\times24\pi = 12\pi \]
\[ S = \frac12 lr = \frac12\times4\pi\times6 = 12\pi \quad\checkmark \]

答案：\(l=4\pi\)，\(S=12\pi\)。

例题 3（扇形周长固定求最大面积）

已知扇形的周长为 8，求它的面积的最大值。

解析

第一步：设变量。设半径为 \(r\)，弧长为 \(l\)。

第二步：用周长条件建立关系。扇形周长 = 两条半径 + 弧长：

\[ 2r+l = 8 \quad\Longrightarrow\quad l = 8-2r \]

第三步：写出面积关于 \(r\) 的表达式。

\[ S = \frac12 lr = \frac12(8-2r)r = 4r-r^{2} \]

第四步：求最大值。这是关于 \(r\) 的二次函数，开口向下：

\[ S = -(r^{2}-4r) = -(r-2)^{2}+4 \]

所以当 \(r=2\) 时，\(S\) 取最大值 4。

验算：\(r=2\) 时 \(l=8-4=4\)，\(S=\dfrac12\times4\times2=4\) ✓。且此时圆心角 \(\alpha=\dfrac lr=2\) rad \(\approx114.6^\circ<2\pi\)，扇形是合法的 ✓。

答案：面积最大值为 \(\boxed{4}\)。

2任意角的三角函数与同角关系

用单位圆定义三角函数，是整章最关键的"思想起点"。后面的所有公式都从这里长出来。

2.1　单位圆定义

定义（★ 整章的地基）

以原点为圆心、半径为 1 的圆叫做单位圆。设任意角 \(\alpha\) 的终边与单位圆交于点 \(P(x,y)\)，规定：

\[ \sin\alpha = y,\qquad \cos\alpha = x,\qquad \tan\alpha=\frac{y}{x}\ (x\ne0) \]

即：纵坐标是正弦，横坐标是余弦，纵坐标除以横坐标是正切。

为什么要用单位圆定义

初中是用直角三角形定义三角函数的（对边比斜边等），但那种定义只能处理 \(0^\circ\sim90^\circ\) 的锐角——三角形里没有钝角，更没有负角。

用单位圆定义就突破了限制：不管角多大、是正还是负，终边总会和单位圆交于一点 \(P\)，这个点的坐标就给出了三个函数值。所以单位圆定义能处理任意角。

2.2　三角函数在各象限的符号

由定义直接得出：\(\sin\alpha\) 的符号 = \(P\) 点纵坐标的符号；\(\cos\alpha\) 的符号 = 横坐标的符号。所以：

象限\(P\) 点坐标\(\sin\alpha\)\(\cos\alpha\)\(\tan\alpha\)
第一象限\((+,\ +)\)\(+\)\(+\)\(+\)
第二象限\((-,\ +)\)\(+\)\(-\)\(-\)
第三象限\((-,\ -)\)\(-\)\(-\)\(+\)
第四象限\((+,\ -)\)\(-\)\(+\)\(-\)
记忆口诀

"一全正、二正弦、三正切、四余弦"

意思是：第一象限三个都正；第二象限只有正弦（\(\sin\)）为正；第三象限只有正切（\(\tan\)）为正；第四象限只有余弦（\(\cos\)）为正。

更好的办法：直接画单位圆。在圆上取四个象限各一点，看坐标的正负，一目了然，不需要背。

2.4　同角三角函数的基本关系

两个基本关系 \[ \sin^{2}\alpha+\cos^{2}\alpha=1 \qquad\qquad \tan\alpha=\frac{\sin\alpha}{\cos\alpha}\ \ (\cos\alpha\ne0) \]
推导一：\(\sin^2\alpha+\cos^2\alpha=1\)

只用一句话：\(P\) 点在单位圆上。

设 \(P(x,y)\) 是角 \(\alpha\) 的终边与单位圆的交点。由定义，\(x=\cos\alpha\)，\(y=\sin\alpha\)。

而 \(P\) 在单位圆上，单位圆的方程是（圆心在原点、半径为 1）：

\[ x^{2}+y^{2}=1 \]

把 \(x=\cos\alpha\)、\(y=\sin\alpha\) 代入：

\[ \cos^{2}\alpha+\sin^{2}\alpha=1 \quad\checkmark \]

几何解释：点 \(P\) 到原点的距离恒为 1（半径）。由勾股定理，横坐标的平方加纵坐标的平方就等于斜边（半径）的平方。这个关系式其实就是勾股定理。

推导二：\(\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}\)

由定义直接得：

\[ \tan\alpha = \frac{y}{x} = \frac{\sin\alpha}{\cos\alpha} \quad\checkmark \]

这就是定义式的改写，只是把 \(y\)、\(x\) 换成了 \(\sin\alpha\)、\(\cos\alpha\)。

注意条件 \(\cos\alpha\ne0\)，即 \(\alpha\ne\dfrac{\pi}{2}+k\pi\)。这些点上正切不存在。

2.5　应用：知一求二

标准解法（三步）
  1. 用平方关系求出另一个函数的平方。由 \(\sin^2\alpha+\cos^2\alpha=1\) 解出未知那个的平方。
  2. 由象限确定符号。开方时会出现正负两个值，用"第几象限"这个条件筛掉一个。
  3. 用商关系求正切。\(\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}\)。

关键：符号是由象限决定的，不是随便取。这一步是本题唯一的难点。

例题 4

已知 \(\sin\alpha=\dfrac35\)，且 \(\alpha\) 是第二象限角，求 \(\cos\alpha\) 和 \(\tan\alpha\)。

解析

第一步：用平方关系求 \(\cos^2\alpha\)。

\[ \cos^{2}\alpha = 1-\sin^{2}\alpha = 1-\left(\frac35\right)^{2} = 1-\frac{9}{25} = \frac{16}{25} \]

第二步：由象限确定符号。\(\alpha\) 是第二象限角，查 2.2 节的表，第二象限余弦为负。所以：

\[ \cos\alpha = -\sqrt{\frac{16}{25}} = -\frac45 \]

第三步：求正切。

\[ \tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{\ \frac35\ }{-\frac45} = \frac35\times\left(-\frac54\right) = -\frac34 \]

验算：\(\sin^2\alpha+\cos^2\alpha=\dfrac{9}{25}+\dfrac{16}{25}=1\) ✓；\(\tan\alpha=\dfrac{3/5}{-4/5}=-\dfrac34\) ✓；第二象限 \(\sin>0\)、\(\cos<0\)、\(\tan<0\)，与结果一致 ✓。

答案：\(\boxed{\cos\alpha=-\dfrac45,\quad \tan\alpha=-\dfrac34}\)

例题 5（已知 \(\tan\alpha\) 求齐次式）

已知 \(\tan\alpha=2\)，求 \(\dfrac{\sin\alpha+2\cos\alpha}{3\sin\alpha-\cos\alpha}\) 的值。

解析

观察：分子分母都是 \(\sin\alpha\) 和 \(\cos\alpha\) 的一次齐次式（每项都是 1 次）。这种式子可以上下同除以 \(\cos\alpha\)，把 \(\sin/\cos\) 换成 \(\tan\)。

第一步：分子分母同除以 \(\cos\alpha\)。

\[ \frac{\sin\alpha+2\cos\alpha}{3\sin\alpha-\cos\alpha} = \frac{\dfrac{\sin\alpha}{\cos\alpha}+2}{3\cdot\dfrac{\sin\alpha}{\cos\alpha}-1} = \frac{\tan\alpha+2}{3\tan\alpha-1} \]

第二步：代入 \(\tan\alpha=2\)。

\[ = \frac{2+2}{3\times2-1} = \frac{4}{5} \]

答案：\(\boxed{\dfrac45}\)

这个技巧的适用范围

只要是关于 \(\sin\alpha\)、\(\cos\alpha\) 的齐次式（每一项的次数都相同），都可以同除以 \(\cos^n\alpha\) 化成 \(\tan\alpha\) 的式子。

  • 一次齐次式（如 \(a\sin\alpha+b\cos\alpha\)）→ 除以 \(\cos\alpha\)
  • 二次齐次式（如 \(\sin^2\alpha+\sin\alpha\cos\alpha\)）→ 除以 \(\cos^2\alpha\)

对于二次齐次式，如果分母是 1，可以先把 1 换成 \(\sin^2\alpha+\cos^2\alpha\)，凑成齐次式再处理。

3诱导公式

这一章有十几条公式，但只需要记住"一个圆 + 一句话"。所有公式都能在 30 秒内推出来。

3.1　推导工具：单位圆的对称性

核心思想（先看懂这一段，后面就简单了）

设角 \(\alpha\) 的终边与单位圆交于点 \(P(x,y)\)，由定义 \(x=\cos\alpha\)，\(y=\sin\alpha\)。

现在关键的一步：如果另一个角 \(\beta\) 的终边与 \(P\) 点有某种对称关系，那么 \(\beta\) 的终边与单位圆的交点 \(P'\) 的坐标就能用 \(x,y\) 表示出来。再用定义读出 \(\sin\beta\)、\(\cos\beta\) 即可。

所以诱导公式的推导只有两步：①找出对称关系 → ②写出 \(P'\) 的坐标 → ③用定义读出结果。

公式一：角相差 \(2k\pi\)（终边重合）

角 \(\alpha+2k\pi\) 与 \(\alpha\) 的终边完全相同，所以交点还是 \(P(x,y)\)：

\[ \sin(\alpha+2k\pi)=\sin\alpha,\qquad \cos(\alpha+2k\pi)=\cos\alpha,\qquad \tan(\alpha+2k\pi)=\tan\alpha \]

这组公式说明三角函数是周期函数——这就是周期性的来源。

公式二：\(\pi+\alpha\)（关于原点对称）

第一步：找对称关系。角 \(\alpha\) 和 \(\pi+\alpha\) 相差半圈（\(180^\circ\)）。转半圈后，点 \(P(x,y)\) 会跑到它关于原点的对称点。

第二步：写出对称点坐标。点 \((x,y)\) 关于原点的对称点是 \((-x,-y)\)，所以 \(P'(-x,-y)\)。

第三步：用定义读出。\(P'\) 的横坐标是 \(\cos(\pi+\alpha)\)，纵坐标是 \(\sin(\pi+\alpha)\)：

\[ \sin(\pi+\alpha)=-y=-\sin\alpha,\qquad \cos(\pi+\alpha)=-x=-\cos\alpha \]
\[ \tan(\pi+\alpha)=\frac{-y}{-x}=\frac{y}{x}=\tan\alpha \]

注意正切：两个负号相除变正，所以 \(\tan(\pi+\alpha)=\tan\alpha\)。

公式三：\(-\alpha\)（关于 \(x\) 轴对称）

对称关系：角 \(-\alpha\) 与 \(\alpha\) 的终边关于 \(x\) 轴对称（顺时针转 \(\alpha\) 与逆时针转 \(\alpha\)，落点关于横轴对称）。

对称点：\((x,y)\) 关于 \(x\) 轴的对称点是 \((x,-y)\)。

\[ \sin(-\alpha)=-y=-\sin\alpha,\qquad \cos(-\alpha)=x=\cos\alpha \]
\[ \tan(-\alpha)=\frac{-y}{x}=-\tan\alpha \]

这组公式说明：\(\cos\) 是偶函数，\(\sin\) 和 \(\tan\) 是奇函数。

公式四：\(\pi-\alpha\)（关于 \(y\) 轴对称）

对称关系：角 \(\pi-\alpha\) 与 \(\alpha\) 的终边关于 \(y\) 轴对称。

对称点：\((x,y)\) 关于 \(y\) 轴的对称点是 \((-x,y)\)。

\[ \sin(\pi-\alpha)=y=\sin\alpha,\qquad \cos(\pi-\alpha)=-x=-\cos\alpha \]
\[ \tan(\pi-\alpha)=\frac{y}{-x}=-\tan\alpha \]

这一组最常用。比如把第二象限的角化到第一象限：\(\sin150^\circ=\sin(180^\circ-30^\circ)=\sin30^\circ=\dfrac12\)。

公式五：\(\dfrac{\pi}{2}-\alpha\)（关于直线 \(y=x\) 对称）

对称关系：角 \(\dfrac{\pi}{2}-\alpha\) 与 \(\alpha\) 的终边关于直线 \(y=x\) 对称。（因为两者之和为 \(\dfrac{\pi}{2}\)，即互余。）

对称点：点 \((x,y)\) 关于直线 \(y=x\) 的对称点是 \((y,x)\)——横纵坐标互换。

\[ \sin\!\left(\frac{\pi}{2}-\alpha\right)=x=\cos\alpha,\qquad \cos\!\left(\frac{\pi}{2}-\alpha\right)=y=\sin\alpha \]

这就是"函数名改变"的来源！正弦变成了余弦，余弦变成了正弦。

正切：

\[ \tan\!\left(\frac{\pi}{2}-\alpha\right)=\frac{x}{y}=\frac{1}{\tan\alpha} \]
公式六：\(\dfrac{\pi}{2}+\alpha\)（拆成两步）

把 \(\dfrac{\pi}{2}+\alpha\) 写成 \(\dfrac{\pi}{2}-(-\alpha)\)，然后连续用公式五和公式三：

\[ \sin\!\left(\frac{\pi}{2}+\alpha\right)=\sin\!\left[\frac{\pi}{2}-(-\alpha)\right]=\cos(-\alpha)=\cos\alpha \]
\[ \cos\!\left(\frac{\pi}{2}+\alpha\right)=\cos\!\left[\frac{\pi}{2}-(-\alpha)\right]=\sin(-\alpha)=-\sin\alpha \]
\[ \tan\!\left(\frac{\pi}{2}+\alpha\right)=\frac{\cos\alpha}{-\sin\alpha}=-\frac{1}{\tan\alpha} \]

注意符号的差别：\(\dfrac{\pi}{2}-\alpha\) 时 \(\cos\) 变成 \(+\sin\alpha\)；\(\dfrac{\pi}{2}+\alpha\) 时 \(\cos\) 变成 \(-\sin\alpha\)。这正是口诀里"符号看象限"要处理的事。

3.2　口诀："奇变偶不变，符号看象限"

逐字拆解这句口诀

当要处理形如 \(\dfrac{k\pi}{2}\pm\alpha\)（\(k\in\mathbb{Z}\)）的角时，用这两句话：

第一句：奇变偶不变。

看 \(\dfrac{\pi}{2}\) 前面的整数系数 \(k\)：

  • \(k\) 是奇数（\(\dfrac{\pi}{2}\)、\(\dfrac{3\pi}{2}\)、\(-\dfrac{\pi}{2}\)……）→ 函数名要变：\(\sin\leftrightarrow\cos\)（\(\tan\) 由 \(\dfrac{\sin}{\cos}\) 直接得到，不用单独记）。
  • \(k\) 是偶数（\(\pi\)、\(2\pi\)、\(0\)、\(-\pi\)……）→ 函数名不变。

为什么？看第 3.1 节的推导就明白了：\(k\) 是奇数时用到的是"关于 \(y=x\) 对称"，坐标互换，所以函数名变了；\(k\) 是偶数时用到的是"关于原点或坐标轴对称"，坐标只是变号，函数名不变。

第二句：符号看象限。

把 \(\alpha\) 当作锐角（不管它实际是多少），判断整个角 \(\dfrac{k\pi}{2}\pm\alpha\) 落在第几象限，然后看原函数在那个象限的符号，把这个符号作为结果的符号。

最容易搞错的一点

"符号看象限"看的是原函数的符号，不是变形后函数的符号。

例如 \(\sin\left(\dfrac{3\pi}{2}+\alpha\right)\)：把 \(\alpha\) 当锐角，则 \(\dfrac{3\pi}{2}+\alpha\) 在第四象限；\(\sin\) 在第四象限是负的，所以结果是负号。因为 \(k=3\) 是奇数，函数名要变：

\[ \sin\!\left(\frac{3\pi}{2}+\alpha\right)=-\cos\alpha \]
例题 6（用口诀求值）

求下列各式的值：

(1) \(\sin 210^\circ\)　　(2) \(\cos 300^\circ\)　　(3) \(\tan 225^\circ\)　　(4) \(\sin\!\left(-\dfrac{11\pi}{6}\right)\)

解析

(1) 把 \(210^\circ\) 写成 \(180^\circ+30^\circ\)（\(k=2\) 为偶数，函数名不变）：

\[ \sin210^\circ=\sin(180^\circ+30^\circ)=-\sin30^\circ=-\frac12 \]

符号判断：把 \(30^\circ\) 当锐角，\(180^\circ+30^\circ=210^\circ\) 在第三象限，\(\sin\) 在第三象限为负，所以取负号。

(2) 把 \(300^\circ\) 写成 \(360^\circ-60^\circ\)：

\[ \cos300^\circ=\cos(360^\circ-60^\circ)=\cos(-60^\circ)=\cos60^\circ=\frac12 \]

符号判断：\(360^\circ-60^\circ=300^\circ\) 在第四象限，\(\cos\) 在第四象限为正，取正号。

(3) 把 \(225^\circ\) 写成 \(180^\circ+45^\circ\)：

\[ \tan225^\circ=\tan(180^\circ+45^\circ)=\tan45^\circ=1 \]

符号判断：\(225^\circ\) 在第三象限，\(\tan\) 在第三象限为正，取正号。

(4) 分两步处理：先化负角，再化到第一象限。

\[ \sin\!\left(-\frac{11\pi}{6}\right)=-\sin\frac{11\pi}{6} \]

（用公式三：\(\sin(-\alpha)=-\sin\alpha\)。）再处理 \(\dfrac{11\pi}{6}\)，把它写成 \(2\pi-\dfrac{\pi}{6}\)：

\[ \sin\frac{11\pi}{6}=\sin\!\left(2\pi-\frac{\pi}{6}\right)=\sin\!\left(-\frac{\pi}{6}\right)=-\sin\frac{\pi}{6}=-\frac12 \]

所以：

\[ \sin\!\left(-\frac{11\pi}{6}\right)=-\left(-\frac12\right)=\boxed{\frac12} \]

验算：\(-\dfrac{11\pi}{6}\) 与 \(\dfrac{\pi}{6}\) 相差 \(2\pi\)（\(-\dfrac{11\pi}{6}+2\pi=\dfrac{\pi}{6}\)），终边相同，所以函数值应该相等。\(\sin\dfrac{\pi}{6}=\dfrac12\) ✓。

化任意角到第一象限的通用流程
  1. 去负号：用 \(\sin(-\alpha)=-\sin\alpha\)、\(\cos(-\alpha)=\cos\alpha\)、\(\tan(-\alpha)=-\tan\alpha\)。
  2. 去整圈：用周期性，减去 \(2k\pi\)（或 \(360^\circ\) 的整数倍），把角化到 \([0,2\pi)\) 内。
  3. 化到锐角：根据角所在的象限，用 \(\pi-\alpha\)、\(\pi+\alpha\)、\(2\pi-\alpha\) 化到第一象限。
  4. 查表或计算。

关于正切函数的三个特别提醒
  • 正切函数没有对称轴，也没有单调区间上的"最大值最小值"。它的图象是一段一段被"断开"的曲线（在 \(x=\dfrac{\pi}{2}+k\pi\) 处有无穷间断点）。
  • 正切的周期是 \(\pi\)，不是 \(2\pi\)。这是最容易记错的地方。
  • "在每一个区间 \(\left(-\dfrac{\pi}{2}+k\pi,\dfrac{\pi}{2}+k\pi\right)\) 上递增"不等于"在定义域上递增"。因为区间之间被断开了，整体不是递增的。
周期性公式的推导

对 \(y=A\sin(\omega x+\varphi)\)（\(\omega>0\)），求周期：

设周期为 \(T\)，则对任意 \(x\) 都有 \(f(x+T)=f(x)\)：

\[ A\sin\bigl[\omega(x+T)+\varphi\bigr]=A\sin(\omega x+\varphi) \]

即 \(\sin(\omega x+\omega T+\varphi)=\sin(\omega x+\varphi)\)。因为 \(\sin\) 的周期是 \(2\pi\)，所以括号里的差必须是 \(2\pi\) 的整数倍，最小正周期对应：

\[ \omega T = 2\pi \quad\Longrightarrow\quad \boxed{\ T=\frac{2\pi}{|\omega|}\ } \]

结论：周期只由 \(\omega\) 决定，与 \(A\)、\(\varphi\) 无关。\(\omega\) 越大，周期越小，图象越"密"。

同理，\(y=A\tan(\omega x+\varphi)\) 的周期是 \(T=\dfrac{\pi}{|\omega|}\)。

4.2　\(y=A\sin(\omega x+\varphi)\) 中各字母的含义

四个参数的物理意义

4.3　★ 图象变换（本章头号易错点）

目标：从 \(y=\sin x\) 得到 \(y=A\sin(\omega x+\varphi)\)（设 \(A>0\)，\(\omega>0\)）。

路径一：先平移，后伸缩（推荐）
  1. 左右平移：\(y=\sin x \ \longrightarrow\ y=\sin(x+\varphi)\)。左移 \(\varphi\) 个单位（\(\varphi>0\) 时）。
  2. 横向伸缩：\(y=\sin(x+\varphi)\ \longrightarrow\ y=\sin(\omega x+\varphi)\)。横坐标缩短为原来的 \(\dfrac{1}{\omega}\)（\(\omega>1\) 时）。
  3. 纵向伸缩：\(y=\sin(\omega x+\varphi)\ \longrightarrow\ y=A\sin(\omega x+\varphi)\)。纵坐标伸长为原来的 \(A\) 倍。

为什么这条路径"友好"？因为第 1 步的平移量就是 \(\varphi\)，不用做任何换算。

路径二：先伸缩，后平移（★ 容易出错）
  1. 横向伸缩：\(y=\sin x\ \longrightarrow\ y=\sin(\omega x)\)。横坐标缩短为原来的 \(\dfrac{1}{\omega}\)。
  2. 左右平移：\(y=\sin(\omega x)\ \longrightarrow\ y=\sin(\omega x+\varphi)\)。此时要左移 \(\dfrac{\varphi}{\omega}\) 个单位，不是 \(\varphi\)！
  3. 纵向伸缩：得到 \(y=A\sin(\omega x+\varphi)\)。
为什么路径二的平移量要除以 \(\omega\)（重要论证）

核心事实：平移变换是对"自变量 \(x\)"本身做的。

第一步：把平移写成替换的形式。把函数 \(y=\sin(\omega x)\) 的图象左移 \(h\) 个单位，等价于把式子里的每个 \(x\) 都换成 \(x+h\)：

\[ y = \sin\bigl[\omega(x+h)\bigr] \]

第二步：展开括号，看希望得到什么。我们想要的结果是 \(\sin(\omega x+\varphi)\)，也就是要满足：

\[ \sin\bigl[\omega(x+h)\bigr] = \sin(\omega x+\varphi) \]

即 \(\omega x+\omega h=\omega x+\varphi\)，所以

\[ \omega h=\varphi \quad\Longrightarrow\quad \boxed{\ h=\frac{\varphi}{\omega}\ } \]

第三步：理解为什么要除。因为括号里 \(\omega\) 把 \(x\) 放大了 \(\omega\) 倍，所以"\(x\) 需要移动多少"就被压缩了 \(\omega\) 倍。要在括号内产生 \(\varphi\) 的变化，\(x\) 只需移动 \(\dfrac{\varphi}{\omega}\)。

反例对照：如果是先平移后伸缩（路径一），第一步 \(y=\sin x\to y=\sin(x+\varphi)\)，这里的平移量就是 \(\varphi\)（因为 \(\omega=1\)，除 1 不变）。之后再横向伸缩时，横坐标变化不会改变"已经平移好"这件事在括号里的效果。

例题 7（两种路径对照）

说明如何由 \(y=\sin x\) 的图象得到 \(y=2\sin\!\left(2x+\dfrac{\pi}{3}\right)\) 的图象。

解析

方法一（先平移后伸缩）：

  1. 把 \(y=\sin x\) 的图象向左平移 \(\dfrac{\pi}{3}\) 个单位，得 \(y=\sin\!\left(x+\dfrac{\pi}{3}\right)\)。
  2. 把所得图象上各点的横坐标缩短为原来的 \(\dfrac12\)（纵坐标不变），得 \(y=\sin\!\left(2x+\dfrac{\pi}{3}\right)\)。
  3. 把所得图象上各点的纵坐标伸长为原来的 2 倍（横坐标不变），得 \(y=2\sin\!\left(2x+\dfrac{\pi}{3}\right)\)。

方法二（先伸缩后平移）：

  1. 把 \(y=\sin x\) 的图象上各点的横坐标缩短为原来的 \(\dfrac12\)，得 \(y=\sin 2x\)。
  2. 把所得图象向左平移 \(\dfrac{\pi}{6}\) 个单位，得 \(y=\sin\!\left[2\left(x+\dfrac{\pi}{6}\right)\right]=\sin\!\left(2x+\dfrac{\pi}{3}\right)\)。
    注意：平移量是 \(\dfrac{\pi}{3}\div2=\dfrac{\pi}{6}\)，不是 \(\dfrac{\pi}{3}\)！
  3. 把所得图象上各点的纵坐标伸长为原来的 2 倍，得 \(y=2\sin\!\left(2x+\dfrac{\pi}{3}\right)\)。

验算（验证两条路径结果一致）：取 \(x=0\)。方法一：先平移得 \(\sin\dfrac{\pi}{3}=\dfrac{\sqrt3}{2}\)，再横向压缩（\(x=0\) 处值不变），最后乘 2 得 \(\sqrt3\)。方法二：\(\sin0=0\to\) 压缩后 \(x=0\) 处仍为 \(0\)，再平移得 \(\sin\left[2\cdot\dfrac{\pi}{6}\right]=\sin\dfrac{\pi}{3}=\dfrac{\sqrt3}{2}\)，最后乘 2 得 \(\sqrt3\) ✓ 一致。

例题 8（逆向：由图象求解析式）

已知函数 \(y=A\sin(\omega x+\varphi)\)（\(A>0\)，\(\omega>0\)，\(|\varphi|<\dfrac{\pi}{2}\)）的图象的一个最高点为 \(\left(\dfrac{\pi}{6},\,2\right)\)，且相邻两条对称轴之间的距离为 \(\dfrac{\pi}{2}\)。求其解析式。

解析

第一步：求 \(A\)。图象的最高点是 \(\left(\dfrac{\pi}{6},2\right)\)，所以最大值是 2，即 \(A=2\)。

第二步：求 \(\omega\)。相邻两条对称轴之间的距离是半个周期（从一个波峰到相邻的波谷，正好是半周期），所以：

\[ \frac{T}{2}=\frac{\pi}{2} \quad\Longrightarrow\quad T=\pi \]

由 \(T=\dfrac{2\pi}{\omega}\) 得：

\[ \omega = \frac{2\pi}{T} = \frac{2\pi}{\pi} = 2 \]

第三步：求 \(\varphi\)（用最高点，最可靠）。

函数在相位 \(\omega x+\varphi=\dfrac{\pi}{2}+2k\pi\) 时取到最大值。把 \(x=\dfrac{\pi}{6}\)、\(\omega=2\) 代入：

\[ 2\times\frac{\pi}{6}+\varphi=\frac{\pi}{2}+2k\pi \quad\Longrightarrow\quad \frac{\pi}{3}+\varphi=\frac{\pi}{2}+2k\pi \]
\[ \varphi=\frac{\pi}{2}-\frac{\pi}{3}+2k\pi=\frac{\pi}{6}+2k\pi \]

由 \(|\varphi|<\dfrac{\pi}{2}\) 得 \(k=0\)，所以 \(\varphi=\dfrac{\pi}{6}\)。

第四步：写出解析式并代回检验。

\[ y=2\sin\!\left(2x+\frac{\pi}{6}\right) \]

检验最高点：\(x=\dfrac{\pi}{6}\) 时，

\[ 2\sin\!\left(2\times\frac{\pi}{6}+\frac{\pi}{6}\right)=2\sin\!\left(\frac{\pi}{3}+\frac{\pi}{6}\right)=2\sin\frac{\pi}{2}=2\times1=2 \quad\checkmark \]

检验周期：\(T=\dfrac{2\pi}{2}=\pi\) ✓，与"相邻对称轴间距 \(\dfrac{\pi}{2}\)"一致。

答案：\(\boxed{y=2\sin\!\left(2x+\dfrac{\pi}{6}\right)}\)

为什么用"最高点"求 \(\varphi\) 最可靠

因为"最高点"同时给出了两条信息：函数值等于 \(A\)（定出 \(A\)），且相位正好等于 \(\dfrac{\pi}{2}+2k\pi\)（定出 \(\varphi\)）。

如果改用"过某点"这种条件，只能得到 \(\sin(\omega x_0+\varphi)=\text{某个值}\)，会解出多个候选相位，还要再筛选，容易出错。

所以：能用最高点/最低点就用它。

求解析式的标准流程
  1. \(A\)：由最大值或最小值确定。\(A=\dfrac{y_{\max}-y_{\min}}{2}\)。
  2. \(\omega\)：由周期确定。已知周期用 \(T=\dfrac{2\pi}{\omega}\)；已知"相邻对称轴间距"用 \(T=2\times\) 间距；已知"相邻零点间距"用 \(T=2\times\) 间距。
  3. \(\varphi\)：用最高点或最低点的坐标代入（令相位等于 \(\dfrac{\pi}{2}+2k\pi\) 或 \(-\dfrac{\pi}{2}+2k\pi\)），再结合 \(|\varphi|\) 的范围确定 \(k\)。
  4. 代回检验：把求出的解析式代入题目的每个条件，逐一验证。

4.4　五点法作图

五个关键点

对 \(y=\sin x\) 在一个周期 \([0,2\pi]\) 内，取相位为 \(0,\dfrac{\pi}{2},\pi,\dfrac{3\pi}{2},2\pi\) 的五个点：

\(x\)\(0\)\(\dfrac{\pi}{2}\)\(\pi\)\(\dfrac{3\pi}{2}\)\(2\pi\)
\(y=\sin x\)\(0\)\(1\)\(0\)\(-1\)\(0\)

对一般形式 \(y=A\sin(\omega x+\varphi)\)，令 \(\omega x+\varphi\) 依次等于上面五个值，反解出对应的 \(x\)：

\[ \omega x+\varphi = 0,\ \frac{\pi}{2},\ \pi,\ \frac{3\pi}{2},\ 2\pi \]

解出的五个 \(x\) 就是作图的关键点，对应的 \(y\) 值是 \(0,A,0,-A,0\)。

5三角恒等变换

这一章公式最多，但推导链最短：一个差角余弦公式，推出全部。

5.1　两角和与差公式

六条公式（只需要记住第一条的推导，其余全部能推） \[ \begin{aligned} \cos(\alpha-\beta) &= \cos\alpha\cos\beta+\sin\alpha\sin\beta \\[4pt] \cos(\alpha+\beta) &= \cos\alpha\cos\beta-\sin\alpha\sin\beta \\[4pt] \sin(\alpha+\beta) &= \sin\alpha\cos\beta+\cos\alpha\sin\beta \\[4pt] \sin(\alpha-\beta) &= \sin\alpha\cos\beta-\cos\alpha\sin\beta \\[4pt] \tan(\alpha+\beta) &= \frac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta} \\[4pt] \tan(\alpha-\beta) &= \frac{\tan\alpha-\tan\beta}{1+\tan\alpha\tan\beta} \end{aligned} \]
★ 核心推导：\(\cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta\)

思路：用同一段距离的两种算法，得出一个等式。

第一步：在单位圆上标出两个点。设角 \(\alpha\) 的终边交单位圆于 \(P_1\)，角 \(\beta\) 的终边交单位圆于 \(P_2\)。由定义：

\[ P_1(\cos\alpha,\ \sin\alpha),\qquad P_2(\cos\beta,\ \sin\beta) \]

第二步：用两点间距离公式算 \(|P_1P_2|^2\)。两点距离公式是 \(d^2=(x_1-x_2)^2+(y_1-y_2)^2\)：

\[ |P_1P_2|^{2} = (\cos\alpha-\cos\beta)^{2}+(\sin\alpha-\sin\beta)^{2} \]

展开两个完全平方：

\[ = \bigl(\cos^{2}\alpha-2\cos\alpha\cos\beta+\cos^{2}\beta\bigr) + \bigl(\sin^{2}\alpha-2\sin\alpha\sin\beta+\sin^{2}\beta\bigr) \]

重新分组，把 \(\cos^2\alpha+\sin^2\alpha\) 放在一起，\(\cos^2\beta+\sin^2\beta\) 放在一起：

\[ = \underbrace{\bigl(\cos^{2}\alpha+\sin^{2}\alpha\bigr)}_{=1} + \underbrace{\bigl(\cos^{2}\beta+\sin^{2}\beta\bigr)}_{=1} - 2\bigl(\cos\alpha\cos\beta+\sin\alpha\sin\beta\bigr) \]

这里用了同角关系 \(\sin^2\theta+\cos^2\theta=1\)：

\[ |P_1P_2|^{2} = 2-2\bigl(\cos\alpha\cos\beta+\sin\alpha\sin\beta\bigr) \tag{①} \]

第三步：用余弦定理再算一次 \(|P_1P_2|^2\)。

在三角形 \(OP_1P_2\) 中，\(OP_1=OP_2=1\)（都是单位圆半径），\(\angle P_1OP_2=|\alpha-\beta|\)。由余弦定理：

\[ |P_1P_2|^{2} = 1^{2}+1^{2}-2\cdot1\cdot1\cdot\cos(\alpha-\beta) = 2-2\cos(\alpha-\beta) \tag{②} \]

第四步：①和②算的是同一个量，令它们相等。

\[ 2-2\bigl(\cos\alpha\cos\beta+\sin\alpha\sin\beta\bigr) = 2-2\cos(\alpha-\beta) \]

两边同时减 2，再同除以 \(-2\)：

\[ \boxed{\ \cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta\ } \]

这条公式是整个三角恒等变换的"种子"，下面所有公式都从它长出来。

从种子长出 \(\cos(\alpha+\beta)\)

技巧：把 \(\beta\) 换成 \(-\beta\)。

因为公式对任意角都成立，所以把其中的 \(\beta\) 全部替换成 \(-\beta\)：

\[ \cos\bigl(\alpha-(-\beta)\bigr)=\cos\alpha\cos(-\beta)+\sin\alpha\sin(-\beta) \]

用诱导公式 \(\cos(-\beta)=\cos\beta\)、\(\sin(-\beta)=-\sin\beta\)：

\[ \cos(\alpha+\beta)=\cos\alpha\cos\beta+\sin\alpha\cdot(-\sin\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta \quad\checkmark \]
从种子长出 \(\sin(\alpha+\beta)\)

技巧：用诱导公式 \(\sin\theta=\cos\left(\dfrac{\pi}{2}-\theta\right)\) 把正弦变余弦。

第一步：

\[ \sin(\alpha+\beta)=\cos\left[\frac{\pi}{2}-(\alpha+\beta)\right] \]

第二步：把括号里整理成"差"的形式。\(\dfrac{\pi}{2}-(\alpha+\beta)=\left(\dfrac{\pi}{2}-\alpha\right)-\beta\)，于是：

\[ = \cos\left[\left(\frac{\pi}{2}-\alpha\right)-\beta\right] \]

第三步：套差角余弦公式。把 \(\dfrac{\pi}{2}-\alpha\) 整体当作第一个角：

\[ = \cos\!\left(\frac{\pi}{2}-\alpha\right)\cos\beta+\sin\!\left(\frac{\pi}{2}-\alpha\right)\sin\beta \]

第四步：用诱导公式（公式五）代入。\(\cos\!\left(\dfrac{\pi}{2}-\alpha\right)=\sin\alpha\)，\(\sin\!\left(\dfrac{\pi}{2}-\alpha\right)=\cos\alpha\)：

\[ \boxed{\ \sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta\ } \]

再把 \(\beta\) 换成 \(-\beta\)，即得 \(\sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta\)。

从种子长出正切公式

技巧：用商关系 \(\tan=\dfrac{\sin}{\cos}\)，再上下同除。

\[ \tan(\alpha+\beta)=\frac{\sin(\alpha+\beta)}{\cos(\alpha+\beta)}=\frac{\sin\alpha\cos\beta+\cos\alpha\sin\beta}{\cos\alpha\cos\beta-\sin\alpha\sin\beta} \]

关键一步：分子分母同除以 \(\cos\alpha\cos\beta\)（要求 \(\cos\alpha\ne0\) 且 \(\cos\beta\ne0\)）：

\[ =\frac{\dfrac{\sin\alpha\cos\beta}{\cos\alpha\cos\beta}+\dfrac{\cos\alpha\sin\beta}{\cos\alpha\cos\beta}}{\dfrac{\cos\alpha\cos\beta}{\cos\alpha\cos\beta}-\dfrac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}} =\frac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta} \quad\checkmark \]

把 \(\beta\) 换成 \(-\beta\)，得 \(\tan(\alpha-\beta)=\dfrac{\tan\alpha-\tan\beta}{1+\tan\alpha\tan\beta}\)。

例题 9

求 \(\cos 15^\circ\) 和 \(\sin 75^\circ\) 的值。

解析

思路：把 \(15^\circ\) 拆成两个特殊角的差。\(15^\circ=45^\circ-30^\circ\)。

\[ \begin{aligned} \cos15^\circ &= \cos(45^\circ-30^\circ) \\ &= \cos45^\circ\cos30^\circ+\sin45^\circ\sin30^\circ \\ &= \frac{\sqrt2}{2}\times\frac{\sqrt3}{2}+\frac{\sqrt2}{2}\times\frac12 \\ &= \frac{\sqrt6}{4}+\frac{\sqrt2}{4} = \frac{\sqrt6+\sqrt2}{4} \end{aligned} \]

对于 \(\sin75^\circ\)：\(75^\circ=45^\circ+30^\circ\)。

\[ \begin{aligned} \sin75^\circ &= \sin(45^\circ+30^\circ) \\ &= \sin45^\circ\cos30^\circ+\cos45^\circ\sin30^\circ \\ &= \frac{\sqrt2}{2}\times\frac{\sqrt3}{2}+\frac{\sqrt2}{2}\times\frac12 = \frac{\sqrt6+\sqrt2}{4} \end{aligned} \]

验算（用余角关系）：\(\sin75^\circ=\cos(90^\circ-75^\circ)=\cos15^\circ\) ✓，两者结果相同，符合预期。

5.2　二倍角公式

推导：在和角公式中令 \(\beta=\alpha\)

这是最省力的推导方式——不需要新方法，只需"取特殊值"。

正弦：在 \(\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta\) 中令 \(\beta=\alpha\)：

\[ \sin(2\alpha)=\sin\alpha\cos\alpha+\cos\alpha\sin\alpha = \boxed{2\sin\alpha\cos\alpha} \]

余弦：在 \(\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta\) 中令 \(\beta=\alpha\)：

\[ \cos2\alpha=\cos^{2}\alpha-\sin^{2}\alpha \]

再用同角关系 \(\sin^2\alpha=1-\cos^2\alpha\) 或 \(\cos^2\alpha=1-\sin^2\alpha\) 变形，得到三个等价形式：

\[ \cos2\alpha=\cos^{2}\alpha-\sin^{2}\alpha \;\overset{\text{用 }\sin^2=1-\cos^2}{=}\; 2\cos^{2}\alpha-1 \;\overset{\text{用 }\cos^2=1-\sin^2}{=}\; 1-2\sin^{2}\alpha \]

验证一下第二种变形：\(\cos^2\alpha-\sin^2\alpha=\cos^2\alpha-(1-\cos^2\alpha)=2\cos^2\alpha-1\) ✓。

正切：在 \(\tan(\alpha+\beta)=\dfrac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}\) 中令 \(\beta=\alpha\)：

\[ \tan2\alpha=\frac{2\tan\alpha}{1-\tan^{2}\alpha} \]
余弦二倍角的三个形式，什么时候用哪个
  • 要求值（已知 \(\cos\alpha\) 或 \(\sin\alpha\)）→ 用对应的那个：已知余弦用 \(2\cos^2\alpha-1\)，已知正弦用 \(1-2\sin^2\alpha\)。
  • 要降幂（把平方变成一次）→ 反解出降幂公式（见 5.3）。
  • 要证明恒等式→ 看哪边更简单就用哪个。
例题 10

已知 \(\sin\alpha=\dfrac35\)，\(\alpha\in\left(0,\dfrac{\pi}{2}\right)\)，求 \(\sin2\alpha\)、\(\cos2\alpha\)、\(\tan2\alpha\)。

解析

第一步：先求 \(\cos\alpha\)。由平方关系：

\[ \cos^{2}\alpha=1-\frac{9}{25}=\frac{16}{25} \]

因为 \(\alpha\in\left(0,\dfrac{\pi}{2}\right)\)（第一象限），余弦为正，所以 \(\cos\alpha=\dfrac45\)。

第二步：求 \(\sin2\alpha\)。

\[ \sin2\alpha=2\sin\alpha\cos\alpha=2\times\frac35\times\frac45=\frac{24}{25} \]

第三步：求 \(\cos2\alpha\)（用两个公式互相验证）。

\[ \cos2\alpha=2\cos^{2}\alpha-1=2\times\frac{16}{25}-1=\frac{32}{25}-\frac{25}{25}=\frac{7}{25} \]
\[ \cos2\alpha=1-2\sin^{2}\alpha=1-2\times\frac{9}{25}=1-\frac{18}{25}=\frac{7}{25} \quad\checkmark \]

第四步：求 \(\tan2\alpha\)。

\[ \tan2\alpha=\frac{\sin2\alpha}{\cos2\alpha}=\frac{\ \frac{24}{25}\ }{\frac{7}{25}}=\frac{24}{7} \]

验算（用万能公式思路）：\(\tan\alpha=\dfrac{3/5}{4/5}=\dfrac34\)，则 \(\tan2\alpha=\dfrac{2\times\frac34}{1-\frac{9}{16}}=\dfrac{\frac32}{\frac{7}{16}}=\dfrac32\times\dfrac{16}{7}=\dfrac{24}{7}\) ✓ 一致。

5.3　降幂公式

推导：从余弦二倍角公式反解

目标：把 \(\cos^2\alpha\) 和 \(\sin^2\alpha\) 表示成一次式。

降余弦的幂：从 \(\cos2\alpha=2\cos^2\alpha-1\) 出发，解出 \(\cos^2\alpha\)：

\[ 2\cos^{2}\alpha=1+\cos2\alpha \quad\Longrightarrow\quad \boxed{\cos^{2}\alpha=\frac{1+\cos2\alpha}{2}} \]

降正弦的幂：从 \(\cos2\alpha=1-2\sin^2\alpha\) 出发，解出 \(\sin^2\alpha\)：

\[ 2\sin^{2}\alpha=1-\cos2\alpha \quad\Longrightarrow\quad \boxed{\sin^{2}\alpha=\frac{1-\cos2\alpha}{2}} \]

怎么记这两个式子？记住"余弦配加号，正弦配减号"：

  • \(\cos^2\) 的分子是 \(1+\cos2\alpha\)（加）
  • \(\sin^2\) 的分子是 \(1-\cos2\alpha\)（减）

为什么？因为 \(\cos2\alpha\) 在 \(\alpha\) 接近 0 时接近 1，此时 \(\cos^2\alpha\) 接近 1 而 \(\sin^2\alpha\) 接近 0。检验：\(\alpha\to0\) 时，\(\dfrac{1+\cos2\alpha}{2}\to\dfrac{1+1}{2}=1\) ✓，\(\dfrac{1-\cos2\alpha}{2}\to0\) ✓。这个"代入特殊值检验"的方法可以用来记任何容易混的公式。

降幂公式的用途

降幂公式的核心作用是把平方变成一次，从而：

  • 求 \(y=\sin^2x\) 或 \(y=\cos^2x\) 的周期、单调区间、最值——化一次之后就是标准的 \(y=A\sin(\omega x+\varphi)+B\) 形式。
  • 处理 \(\sin^2x+\sin x\cos x\) 这类二次齐次式的化简。

典型例题：求 \(y=\sin^2x+\sqrt3\sin x\cos x\) 的最小正周期和值域。

用降幂公式和倍角公式：

\[ y=\frac{1-\cos2x}{2}+\frac{\sqrt3}{2}\sin2x=\frac12-\frac12\cos2x+\frac{\sqrt3}{2}\sin2x \]

再用辅助角公式（见 5.4）：

\[ y=\frac12+\sin\!\left(2x-\frac{\pi}{6}\right) \]

所以最小正周期 \(T=\pi\)，值域为 \(\left[-\dfrac12,\ \dfrac32\right]\)。

5.4　辅助角公式

公式
\[ \boxed{\ a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\,\sin(x+\varphi)\ } \]

其中 \(\varphi\) 由 \(\cos\varphi=\dfrac{a}{\sqrt{a^2+b^2}}\)、\(\sin\varphi=\dfrac{b}{\sqrt{a^2+b^2}}\) 确定，即 \(\tan\varphi=\dfrac{b}{a}\)。

（也可以写成 \(\sqrt{a^2+b^2}\cos(x-\theta)\) 的形式，视题目方便选用。）

推导：提取公因式 + 用和角公式

核心想法：想办法把 \(a\sin x+b\cos x\) 凑成 \(\sin x\cos\varphi+\cos x\sin\varphi\) 的形式。

第一步：提出 \(\sqrt{a^2+b^2}\)。

\[ a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\left(\frac{a}{\sqrt{a^{2}+b^{2}}}\sin x+\frac{b}{\sqrt{a^{2}+b^{2}}}\cos x\right) \]

第二步：验证括号里两个系数满足"平方和为 1"。

\[ \left(\frac{a}{\sqrt{a^{2}+b^{2}}}\right)^{2}+\left(\frac{b}{\sqrt{a^{2}+b^{2}}}\right)^{2}=\frac{a^{2}+b^{2}}{a^{2}+b^{2}}=1 \]

这是最关键的一步。平方和为 1 意味着：这两个数可以看作某个角的余弦和正弦（因为单位圆上点的坐标平方和就是 1）。

第三步：设角 \(\varphi\)。令

\[ \cos\varphi=\frac{a}{\sqrt{a^{2}+b^{2}}},\qquad \sin\varphi=\frac{b}{\sqrt{a^{2}+b^{2}}} \]

这样的 \(\varphi\) 一定存在（由第二步的平方和关系保证），且 \(\tan\varphi=\dfrac{b}{a}\)。

第四步：代入并套和角公式。

\[ a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\bigl(\sin x\cos\varphi+\cos x\sin\varphi\bigr)=\sqrt{a^{2}+b^{2}}\sin(x+\varphi) \quad\checkmark \]

为什么要这样做？因为 \(\sin x\) 和 \(\cos x\) 的线性组合不好处理（周期、最值都不直观），但变成单个正弦函数后，周期、值域、单调性全都一目了然。

例题 11

把下列式子化成 \(A\sin(x+\varphi)\) 的形式：

(1) \(\sin x+\sqrt3\cos x\)　　(2) \(\sqrt3\sin x-\cos x\)

解析

(1) 这里 \(a=1\)，\(b=\sqrt3\)，所以：

\[ \sqrt{a^{2}+b^{2}}=\sqrt{1+3}=2 \]

则 \(\cos\varphi=\dfrac12\)，\(\sin\varphi=\dfrac{\sqrt3}{2}\)，所以 \(\varphi=\dfrac{\pi}{3}\)。因此：

\[ \sin x+\sqrt3\cos x=2\sin\!\left(x+\frac{\pi}{3}\right) \]

验算：取 \(x=0\)，左边 \(=0+\sqrt3=\sqrt3\)；右边 \(=2\sin\dfrac{\pi}{3}=2\times\dfrac{\sqrt3}{2}=\sqrt3\) ✓。

(2) 这里 \(a=\sqrt3\)，\(b=-1\)，所以：

\[ \sqrt{a^{2}+b^{2}}=\sqrt{3+1}=2 \]

则 \(\cos\varphi=\dfrac{\sqrt3}{2}\)，\(\sin\varphi=-\dfrac12\)，所以 \(\varphi=-\dfrac{\pi}{6}\)。因此：

\[ \sqrt3\sin x-\cos x=2\sin\!\left(x-\frac{\pi}{6}\right) \]

验算：取 \(x=0\)，左边 \(=0-1=-1\)；右边 \(=2\sin\left(-\dfrac{\pi}{6}\right)=2\times\left(-\dfrac12\right)=-1\) ✓。

\(b\) 是负数怎么办

不要慌，按公式老老实实写 \(\sin\varphi=\dfrac{b}{\sqrt{a^2+b^2}}\)，\(\varphi\) 自然会是负角（第四象限角）。不要因为怕负号就把 \(b\) 当成正的，那样结果会错。

例题 12（辅助角公式的典型应用）

求函数 \(f(x)=\sin x+\sqrt3\cos x\) 的最大值、最小值，以及取得最大值时 \(x\) 的集合。

解析

第一步：化成单个正弦函数。由例题 11 的结果：

\[ f(x)=2\sin\!\left(x+\frac{\pi}{3}\right) \]

第二步：求最值。因为 \(\sin\) 的取值范围是 \([-1,1]\)，所以：

\[ f(x)_{\max}=2\times1=2,\qquad f(x)_{\min}=2\times(-1)=-2 \]

第三步：求取最大值时的 \(x\)。要求 \(\sin\!\left(x+\dfrac{\pi}{3}\right)=1\)，即相位等于 \(\dfrac{\pi}{2}+2k\pi\)：

\[ x+\frac{\pi}{3}=\frac{\pi}{2}+2k\pi \quad\Longrightarrow\quad x=\frac{\pi}{6}+2k\pi \]

答案：最大值为 \(2\)，最小值为 \(-2\)；取最大值时 \(x\) 的集合为

\[ \boxed{\left\{\,x\ \middle|\ x=\frac{\pi}{6}+2k\pi,\ k\in\mathbb{Z}\,\right\}} \]

验算：取 \(k=0\)，\(x=\dfrac{\pi}{6}\)。\(f\left(\dfrac{\pi}{6}\right)=\sin\dfrac{\pi}{6}+\sqrt3\cos\dfrac{\pi}{6}=\dfrac12+\sqrt3\times\dfrac{\sqrt3}{2}=\dfrac12+\dfrac32=2\) ✓。

5.5　半角公式

降幂公式的"逆向使用"：知道 \(\cos\alpha\)，就能求出 \(\dfrac{\alpha}{2}\) 的正弦、余弦、正切。化简 \(1+\cos\alpha\)、\(1-\cos\alpha\) 这类式子时非常好用，是高考小题的高频工具。

公式

把降幂公式（5.3 节）里的角"减半"，就得到半角公式的平方形式：

\[ \sin^{2}\frac{\alpha}{2}=\frac{1-\cos\alpha}{2},\qquad \cos^{2}\frac{\alpha}{2}=\frac{1+\cos\alpha}{2} \]

开方就得到一次形式（正负号由 \(\dfrac{\alpha}{2}\) 所在象限决定）：

\[ \sin\frac{\alpha}{2}=\pm\sqrt{\frac{1-\cos\alpha}{2}},\qquad \cos\frac{\alpha}{2}=\pm\sqrt{\frac{1+\cos\alpha}{2}} \]

正切用"正弦 ÷ 余弦"，整理后有三个等价形式：

\[ \tan\frac{\alpha}{2}=\pm\sqrt{\frac{1-\cos\alpha}{1+\cos\alpha}}=\frac{1-\cos\alpha}{\sin\alpha}=\frac{\sin\alpha}{1+\cos\alpha} \]

★ 后两个形式没有根号、也没有 \(\pm\)，是考试里最常用的。用的时候只要注意分母不为 0：第一个要求 \(\sin\alpha\ne0\)，第二个要求 \(1+\cos\alpha\ne0\)。

推导：为什么 \(\tan\dfrac{\alpha}{2}=\dfrac{1-\cos\alpha}{\sin\alpha}\)

第一步：把降幂公式的角减半。降幂公式（5.3 节）是：

\[ \cos^{2}\theta=\frac{1+\cos 2\theta}{2},\qquad \sin^{2}\theta=\frac{1-\cos 2\theta}{2} \]

把 \(\theta\) 换成 \(\dfrac{\alpha}{2}\)（于是 \(2\theta=\alpha\)）：

\[ \cos^{2}\frac{\alpha}{2}=\frac{1+\cos\alpha}{2},\qquad \sin^{2}\frac{\alpha}{2}=\frac{1-\cos\alpha}{2} \]

这两式开方就是上面公式表里带 \(\pm\) 的那两行。下面重点推正切。

第二步：把 \(1-\cos\alpha\) 和 \(\sin\alpha\) 都写成"半角的式子"。由第一步两式各乘 2：

\[ 1-\cos\alpha=2\sin^{2}\frac{\alpha}{2} \]

再由二倍角公式 \(\sin 2\theta=2\sin\theta\cos\theta\)（取 \(\theta=\dfrac{\alpha}{2}\)）：

\[ \sin\alpha=2\sin\frac{\alpha}{2}\cos\frac{\alpha}{2} \]

第三步：相除，约掉公因式。

\[ \frac{1-\cos\alpha}{\sin\alpha}=\frac{2\sin^{2}\dfrac{\alpha}{2}}{2\sin\dfrac{\alpha}{2}\cos\dfrac{\alpha}{2}}=\frac{\sin\dfrac{\alpha}{2}}{\cos\dfrac{\alpha}{2}}=\tan\frac{\alpha}{2} \quad\checkmark \]

注意：这里没有出现 \(\pm\)。因为这是"整式相除"，正负号已经自动由 \(\sin\alpha\) 的符号带上了——这正是它比根号形式好用的原因。

第四步：另一个形式同理。这次用 \(1+\cos\alpha=2\cos^{2}\dfrac{\alpha}{2}\)，再与 \(\sin\alpha=2\sin\dfrac{\alpha}{2}\cos\dfrac{\alpha}{2}\) 相除：

\[ \frac{\sin\alpha}{1+\cos\alpha}=\frac{2\sin\dfrac{\alpha}{2}\cos\dfrac{\alpha}{2}}{2\cos^{2}\dfrac{\alpha}{2}}=\frac{\sin\dfrac{\alpha}{2}}{\cos\dfrac{\alpha}{2}}=\tan\frac{\alpha}{2} \quad\checkmark \]
例题（半角公式的三种考法）

(1) 已知 \(\cos\alpha=-\dfrac{3}{5}\)，且 \(\alpha\in\left(\dfrac{\pi}{2},\pi\right)\)，求 \(\sin\dfrac{\alpha}{2}\)。

(2) 化简 \(\dfrac{1-\cos\alpha}{\sin\alpha}\)。

(3) 求证 \(\tan\left(\dfrac{\pi}{4}-\dfrac{A}{2}\right)=\dfrac{1-\sin A}{\cos A}\)。

解析

(1) 先定象限，再定符号。因为 \(\alpha\in\left(\dfrac{\pi}{2},\pi\right)\)，所以

\[ \frac{\alpha}{2}\in\left(\frac{\pi}{4},\frac{\pi}{2}\right) \]

即 \(\dfrac{\alpha}{2}\) 在第一象限，\(\sin\dfrac{\alpha}{2}>0\)，取正号：

\[ \sin\frac{\alpha}{2}=\sqrt{\frac{1-\cos\alpha}{2}}=\sqrt{\frac{1-\left(-\dfrac35\right)}{2}}=\sqrt{\frac{8/5}{2}}=\sqrt{\frac45}=\frac{2\sqrt5}{5} \]

答案：\(\boxed{\dfrac{2\sqrt5}{5}}\)

验算：\(\dfrac{2\sqrt5}{5}\approx0.894\)。由 \(\cos\alpha=-\dfrac35\) 得 \(\alpha\approx126.87^\circ\)，\(\dfrac{\alpha}{2}\approx63.43^\circ\)，\(\sin63.43^\circ\approx0.894\) ✓。

(2) 直接套第三步的结论：

\[ \frac{1-\cos\alpha}{\sin\alpha}=\tan\frac{\alpha}{2} \]

这就是半角公式最常见的"认出题"方式——看到"\(1-\cos\alpha\) 除以 \(\sin\alpha\)"，立刻想到它等于 \(\tan\dfrac{\alpha}{2}\)。同理，"\(\sin\alpha\) 除以 \(1+\cos\alpha\)"也等于 \(\tan\dfrac{\alpha}{2}\)。

(3) 把 \(\dfrac{\pi}{4}-\dfrac{A}{2}\) 看成"半个角"。令 \(\alpha=\dfrac{\pi}{2}-A\)，则 \(\dfrac{\alpha}{2}=\dfrac{\pi}{4}-\dfrac{A}{2}\)。代入 \(\tan\dfrac{\alpha}{2}=\dfrac{1-\cos\alpha}{\sin\alpha}\)：

\[ \tan\left(\frac{\pi}{4}-\frac{A}{2}\right)=\frac{1-\cos\alpha}{\sin\alpha}=\frac{1-\cos\left(\dfrac{\pi}{2}-A\right)}{\sin\left(\dfrac{\pi}{2}-A\right)}=\frac{1-\sin A}{\cos A} \quad\checkmark \]

（这里用了诱导公式 \(\cos\left(\dfrac{\pi}{2}-A\right)=\sin A\)、\(\sin\left(\dfrac{\pi}{2}-A\right)=\cos A\)，见 3.1 节。）

易错点
  • \(\pm\) 不能"随便取"。必须由 \(\dfrac{\alpha}{2}\) 所在象限决定。题目不告诉象限时就要分类讨论。
  • 不要和降幂公式记混。降幂公式右边是 \(\dfrac{1+\cos 2\alpha}{2}\)（角加倍），半角公式右边是 \(\dfrac{1+\cos\alpha}{2}\)（角减半）。看角是加倍还是减半，就知道用哪个。
  • 用分式形式要检查分母。\(\tan\dfrac{\alpha}{2}=\dfrac{1-\cos\alpha}{\sin\alpha}\) 要求 \(\alpha\ne k\pi\)；\(\tan\dfrac{\alpha}{2}=\dfrac{\sin\alpha}{1+\cos\alpha}\) 要求 \(\alpha\ne\pi+2k\pi\)。哪个分母不为 0 就用哪个。

6解三角形

两个定理 + 一个面积公式，就能解决大部分三角形问题。关键是把定理的推导看懂，知道什么时候用哪个。

6.1　正弦定理

定理

在 \(\triangle ABC\) 中，角 \(A,B,C\) 所对的边分别是 \(a,b,c\)，外接圆半径为 \(R\)，则

\[ \boxed{\ \frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=2R\ } \]
推导：用外接圆和直径所对的圆周角

目标：证明 \(\dfrac{a}{\sin A}=2R\)。（其余两个同理。）

第一步：构造直径。作 \(\triangle ABC\) 的外接圆（圆心 \(O\)，半径 \(R\)）。连接 \(BO\) 并延长，交圆于点 \(D\)，则 \(BD\) 是直径，长度为 \(2R\)。

第二步：利用"直径所对的圆周角是直角"。因为 \(BD\) 是直径，所以 \(\angle BCD=90^\circ\)。于是三角形 \(BCD\) 是直角三角形，且 \(BD\) 是斜边。

第三步：利用"同弧所对的圆周角相等"。\(\angle D\) 和 \(\angle A\) 都是弧 \(BC\) 所对的圆周角，所以 \(\angle D=\angle A\)。

第四步：在直角三角形 \(BCD\) 中用锐角三角函数。

\[ \sin D=\frac{\text{对边}}{\text{斜边}}=\frac{BC}{BD}=\frac{a}{2R} \]

因为 \(\angle D=\angle A\)，所以 \(\sin A=\dfrac{a}{2R}\)，即

\[ \frac{a}{\sin A}=2R \quad\checkmark \]

同理可证 \(\dfrac{b}{\sin B}=2R\)、\(\dfrac{c}{\sin C}=2R\)。

当 \(A\) 是钝角时怎么办

上面的证明假设 \(A\) 是锐角。如果 \(A\) 是钝角，\(A\) 与 \(D\) 就分居 \(BC\) 的两侧，此时 \(ABDC\) 是圆内接四边形，对角互补，所以 \(\angle D=180^\circ-A\)。又因为 \(BD\) 是直径，\(\angle BCD=90^\circ\)，所以 \(\angle D\) 一定是锐角（\(\angle D<90^\circ\)），不可能取到钝角——这与 \(A\) 为钝角并不矛盾。

于是 \(\sin D=\sin(180^\circ-A)=\sin A\)，代入 \(a=BD\cdot\sin D=2R\sin A\) 仍然成立，结论不变。

考试中不需要写这种分类讨论，直接使用定理即可。

正弦定理的三种用法（看已知什么）
已知条件求什么怎么用
两角 + 一边（AAS / ASA）其余边直接用 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}\)
两边 + 其中一边的对角（SSA）其余角用 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}\) 求角。★ 可能有 0、1、2 个解
边角混合的等式判断形状 / 求角把边都换成 \(\sin\)（用 \(a=2R\sin A\)），统一成角的关系
★ 正弦定理最大的坑：SSA 的多解问题

已知两边和其中一边的对角（如已知 \(a,b,A\)）时，求 \(B\) 会出现 \(B\) 和 \(180^\circ-B\) 两个候选值（因为 \(\sin B=\sin(180^\circ-B)\)）。必须检验两个值是否都满足 \(A+B<180^\circ\)。

检验方法：算出 \(B\) 的两个候选值，分别算 \(A+B\)，只有 \(A+B<180^\circ\) 的才保留。

为什么？因为三角形内角和必须是 \(180^\circ\)。如果 \(A+B\ge180^\circ\)，那么 \(C\le0\)，三角形不存在。

例题 13（正弦定理基本用法）

在 \(\triangle ABC\) 中，已知 \(a=2\)，\(A=30^\circ\)，\(B=45^\circ\)。求 \(b\)。

解析

由正弦定理：

\[ \frac{a}{\sin A}=\frac{b}{\sin B} \quad\Longrightarrow\quad \frac{2}{\sin30^\circ}=\frac{b}{\sin45^\circ} \]

因为 \(\sin30^\circ=\dfrac12\)、\(\sin45^\circ=\dfrac{\sqrt2}{2}\)：

\[ \frac{2}{\frac12}=\frac{b}{\frac{\sqrt2}{2}} \quad\Longrightarrow\quad 4=\frac{2b}{\sqrt2} \quad\Longrightarrow\quad b=\frac{4\sqrt2}{2}=2\sqrt2 \]

答案：\(\boxed{b=2\sqrt2}\)

验算：\(\dfrac{b}{\sin B}=\dfrac{2\sqrt2}{\frac{\sqrt2}{2}}=2\sqrt2\times\dfrac{2}{\sqrt2}=4=\dfrac{a}{\sin A}\) ✓，比值相等。

例题 14（SSA 多解问题）

在 \(\triangle ABC\) 中，已知 \(a=\sqrt2\)，\(b=2\)，\(A=30^\circ\)。求 \(B\)。

解析

第一步：用正弦定理求 \(\sin B\)。

\[ \frac{a}{\sin A}=\frac{b}{\sin B} \quad\Longrightarrow\quad \frac{\sqrt2}{\sin30^\circ}=\frac{2}{\sin B} \]
\[ \frac{\sqrt2}{\frac12}=\frac{2}{\sin B} \quad\Longrightarrow\quad 2\sqrt2=\frac{2}{\sin B} \quad\Longrightarrow\quad \sin B=\frac{2}{2\sqrt2}=\frac{\sqrt2}{2} \]

第二步：解出 \(B\) 的所有候选值。因为 \(\sin B=\dfrac{\sqrt2}{2}\)，所以在 \((0^\circ,180^\circ)\) 内 \(B\) 有两个可能：

\[ B=45^\circ \quad\text{或}\quad B=135^\circ \]

第三步：逐一检验 \(A+B<180^\circ\)。

  • 若 \(B=45^\circ\)：\(A+B=30^\circ+45^\circ=75^\circ<180^\circ\) ✓ 可行，此时 \(C=105^\circ\)。
  • 若 \(B=135^\circ\)：\(A+B=30^\circ+135^\circ=165^\circ<180^\circ\) ✓ 也可行，此时 \(C=15^\circ\)。

两个解都成立！

第四步：进一步检验（重要）。还需要检查大边对大角是否合理。因为 \(b=2>a=\sqrt2\)，所以应有 \(B>A=30^\circ\)，两个候选值都满足 ✓。

答案：\(\boxed{B=45^\circ\ \text{或}\ B=135^\circ}\)

这道题的启示

SSA 情形下出现两个解不是错误，而是几何事实：同样的两条边和夹角条件，可以构造出两个不同的三角形。

所以做这类题必须：①解出所有候选值 ②逐一检验 \(A+B<180^\circ\) ③必要时用"大边对大角"辅助筛选。

如果题目明确说"\(B\) 是锐角"或"三角形是钝角三角形"，就能筛掉一个。

6.2　余弦定理

定理

在 \(\triangle ABC\) 中：

\[ \begin{aligned} a^{2} &= b^{2}+c^{2}-2bc\cos A \\ b^{2} &= a^{2}+c^{2}-2ac\cos B \\ c^{2} &= a^{2}+b^{2}-2ab\cos C \end{aligned} \]

变形（用来求角）：

\[ \cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc},\qquad \cos B=\frac{a^{2}+c^{2}-b^{2}}{2ac},\qquad \cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab} \]
推导：用向量（最简洁）

第一步：把边长写成向量的模。设 \(\overrightarrow{AB}\)、\(\overrightarrow{AC}\)、\(\overrightarrow{BC}\) 是从同一点出发的向量。由向量加法的三角形法则：

\[ \overrightarrow{BC}=\overrightarrow{AC}-\overrightarrow{AB} \]

两边取模长的平方：

\[ |\overrightarrow{BC}|^{2}=|\overrightarrow{AC}-\overrightarrow{AB}|^{2} \]

第二步：展开右边。利用 \(|u-v|^2=|u|^2+|v|^2-2u\cdot v\)：

\[ |\overrightarrow{BC}|^{2}=|\overrightarrow{AC}|^{2}+|\overrightarrow{AB}|^{2}-2\,\overrightarrow{AC}\cdot\overrightarrow{AB} \]

第三步：把每个量换成边长和角。

  • \(|\overrightarrow{BC}|=a\)，所以 \(|\overrightarrow{BC}|^2=a^2\)
  • \(|\overrightarrow{AC}|=b\)，所以 \(|\overrightarrow{AC}|^2=b^2\)
  • \(|\overrightarrow{AB}|=c\)，所以 \(|\overrightarrow{AB}|^2=c^2\)
  • \(\overrightarrow{AC}\cdot\overrightarrow{AB}=|\overrightarrow{AC}||\overrightarrow{AB}|\cos A=bc\cos A\)（数量积定义，夹角就是 \(\angle A\)）

代入：

\[ \boxed{\ a^{2}=b^{2}+c^{2}-2bc\cos A\ } \]

同理可证另外两个。∎

不用向量的推导（坐标法）

把点 \(A\) 放在原点，\(AB\) 沿 \(x\) 轴，则 \(B(c,0)\)，\(C(b\cos A,\ b\sin A)\)。用两点间距离公式算 \(BC\)：

\[ a^{2}=BC^{2}=(b\cos A-c)^{2}+(b\sin A)^{2}=b^{2}\cos^{2}A-2bc\cos A+c^{2}+b^{2}\sin^{2}A \]

用 \(\cos^2A+\sin^2A=1\) 合并：\(a^{2}=b^{2}+c^{2}-2bc\cos A\) ✓ 同样得到结论。

余弦定理的用法
已知条件求什么怎么用
两边 + 夹角（SAS）第三边直接用 \(a^2=b^2+c^2-2bc\cos A\)
三边（SSS）角用 \(\cos A=\dfrac{b^2+c^2-a^2}{2bc}\)
边角混合等式求角 / 判断形状把角换成边（或反过来），统一后再用

与正弦定理的分工：

  • 已知"角对角"的关系（两角一边、两边一对角）→ 正弦定理。
  • 已知"边夹边"或"三边"（SAS、SSS）→ 余弦定理。
例题 15

在 \(\triangle ABC\) 中，已知 \(a=3\)，\(b=4\)，\(C=60^\circ\)。求 \(c\)。

解析

这是 SAS 情形，用余弦定理：

\[ c^{2}=a^{2}+b^{2}-2ab\cos C=3^{2}+4^{2}-2\times3\times4\times\cos60^\circ \]
\[ c^{2}=9+16-24\times\frac12=25-12=13 \]

因为边长必须为正，所以：

\[ \boxed{c=\sqrt{13}} \]

验算：检验三角形不等式 \(a+b>c\)：\(3+4=7>\sqrt{13}\approx3.61\) ✓；\(|a-b|<c\)：\(1<3.61\) ✓。三角形存在。

例题 16（判断三角形形状）

在 \(\triangle ABC\) 中，已知 \(a\cos B=b\cos A\)。判断 \(\triangle ABC\) 的形状。

解析

思路：把边换成角，用正弦定理。由 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=2R\)，得

\[ a=2R\sin A,\qquad b=2R\sin B \]

代入已知条件 \(a\cos B=b\cos A\)：

\[ 2R\sin A\cos B=2R\sin B\cos A \]

两边约去 \(2R\)（\(R>0\)）：

\[ \sin A\cos B=\sin B\cos A \]

移项：

\[ \sin A\cos B-\cos A\sin B=0 \]

关键：识别出这是差角正弦公式。由 \(\sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta\)，左边就是 \(\sin(A-B)\)：

\[ \sin(A-B)=0 \]

因为 \(A,B\) 是三角形内角，都在 \((0,\pi)\) 内，所以 \(A-B\in(-\pi,\pi)\)。在这个范围内 \(\sin(A-B)=0\) 意味着：

\[ A-B=0 \quad\Longrightarrow\quad A=B \]

所以 \(a=b\)（等角对等边）。

答案：\(\triangle ABC\) 是等腰三角形（\(a=b\)，即 \(A=B\)）。

验算（用余弦定理的另一条路）：把 \(\cos A=\dfrac{b^2+c^2-a^2}{2bc}\)、\(\cos B=\dfrac{a^2+c^2-b^2}{2ac}\) 代入原式：

\[ a\cdot\frac{a^{2}+c^{2}-b^{2}}{2ac}=b\cdot\frac{b^{2}+c^{2}-a^{2}}{2bc} \quad\Longrightarrow\quad \frac{a^{2}+c^{2}-b^{2}}{2c}=\frac{b^{2}+c^{2}-a^{2}}{2c} \]
\[ a^{2}+c^{2}-b^{2}=b^{2}+c^{2}-a^{2} \quad\Longrightarrow\quad 2a^{2}=2b^{2} \quad\Longrightarrow\quad a=b \quad\checkmark \]

两条路得到同样的结论。

6.3　三角形面积公式

公式
\[ S=\frac12 ab\sin C=\frac12 bc\sin A=\frac12 ac\sin B \]

规律：两边之积乘以它们的夹角的正弦，再除以 2。

推导：用"底 × 高 ÷ 2"

第一步：以 \(BC\) 为底。取边 \(BC\) 作为底边，长度是 \(a\)。

第二步：求这条底边上的高。过点 \(A\) 作 \(BC\) 的垂线，垂足为 \(D\)，则高 \(h=AD\)。

在直角三角形 \(ACD\) 中，斜边是 \(AC=b\)，\(\angle ACD=C\)（当 \(C\) 为锐角时），所以：

\[ h=AD=AC\cdot\sin C=b\sin C \]

（当 \(C\) 为钝角时，\(\sin C=\sin(180^\circ-C)\)，结论仍然成立。）

第三步：代入三角形面积公式。

\[ S=\frac12\times\text{底}\times\text{高}=\frac12\times a\times b\sin C=\frac12 ab\sin C \quad\checkmark \]

同理，换一个底边就能得到另外两个形式。

例题 17

在 \(\triangle ABC\) 中，已知 \(b=2\)，\(c=3\)，\(A=60^\circ\)。求三角形的面积 \(S\) 和边 \(a\)。

解析

求面积：已知的是 \(b\)、\(c\) 和它们的夹角 \(A\)，直接用面积公式：

\[ S=\frac12 bc\sin A=\frac12\times2\times3\times\sin60^\circ=3\times\frac{\sqrt3}{2}=\frac{3\sqrt3}{2} \]

求边 \(a\)：用余弦定理（SAS 情形）：

\[ a^{2}=b^{2}+c^{2}-2bc\cos A=4+9-2\times2\times3\times\frac12=13-6=7 \]
\[ a=\sqrt7 \]

答案：\(\boxed{S=\dfrac{3\sqrt3}{2},\quad a=\sqrt7}\)

验算（用面积公式的另一个形式反推）：\(S=\dfrac12 ab\sin C\)，需要先求 \(\sin C\)。由正弦定理 \(\dfrac{a}{\sin A}=\dfrac{c}{\sin C}\)：

\[ \frac{\sqrt7}{\frac{\sqrt3}{2}}=\frac{3}{\sin C} \quad\Longrightarrow\quad \sin C=\frac{3\times\frac{\sqrt3}{2}}{\sqrt7}=\frac{3\sqrt3}{2\sqrt7} \]

则 \(S=\dfrac12\times\sqrt7\times2\times\dfrac{3\sqrt3}{2\sqrt7}=\dfrac{3\sqrt3}{2}\) ✓ 一致。

例题 18（已知三边求面积）

在 \(\triangle ABC\) 中，已知 \(a=3\)，\(b=4\)，\(c=\sqrt{13}\)。求角 \(C\) 和面积 \(S\)。

解析

第一步：用余弦定理求角。求 \(C\) 就用含 \(C\) 的那条：

\[ \cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=\frac{9+16-13}{2\times3\times4}=\frac{12}{24}=\frac12 \]

因为 \(C\in(0,\pi)\)，所以 \(C=\dfrac{\pi}{3}=60^\circ\)。

第二步：求面积。现在有了 \(a\)、\(b\) 和夹角 \(C\)：

\[ S=\frac12 ab\sin C=\frac12\times3\times4\times\sin60^\circ=6\times\frac{\sqrt3}{2}=3\sqrt3 \]

答案：\(\boxed{C=60^\circ,\quad S=3\sqrt3}\)

验算：这与例题 15、17 的数据其实是同一组（\(a=3,b=4,C=60^\circ\Rightarrow c=\sqrt{13}\)），结果一致 ✓。

6.4　三角形中的常用关系

四条必须记住的"内角和"推论

因为 \(A+B+C=\pi\)，所以 \(A+B=\pi-C\)：

\[ \begin{aligned} \sin(A+B) &= \sin(\pi-C)=\sin C \\[4pt] \cos(A+B) &= \cos(\pi-C)=-\cos C \\[4pt] \tan(A+B) &= \tan(\pi-C)=-\tan C \\[4pt] \sin\frac{A+B}{2} &= \sin\left(\frac{\pi}{2}-\frac{C}{2}\right)=\cos\frac{C}{2} \end{aligned} \]

用途：题目里出现 \(\sin(A+B)\)、\(\cos(A+B)\) 这类式子时，立刻换成含 \(C\) 的式子，就能化简。

常见搭配：在 \(\triangle ABC\) 中，"\(\sin(A+B)=\sin C\)"和"\(\cos(A+B)=-\cos C\)"这两个等式在边角互化时用得极多。

判断三角形形状的常用结论
条件结论
\(a^2+b^2=c^2\)直角三角形（\(C=90^\circ\)）
\(a^2+b^2>c^2\)\(C\) 为锐角
\(a^2+b^2<c^2\)\(C\) 为钝角
\(a=b\) 或 \(A=B\)等腰三角形
\(a=b=c\) 或 \(A=B=C\)等边三角形
\(\sin2A=\sin2B\)\(A=B\) 或 \(A+B=90^\circ\)，即等腰或直角

最后一条要特别注意：由 \(\sin2A=\sin2B\) 推出的是 \(2A=2B\) 或 \(2A+2B=180^\circ\)，即 \(A=B\) 或 \(A+B=90^\circ\)。两种都可能，不能只写一种。

8.1　题型一：恒等变换 + 图象性质

题型特征与解题套路

特征：给出一个三角式（含平方、乘积、不同角），要求周期、单调区间、最值。

套路（三步走）：

  1. 降幂：把 \(\sin^2\)、\(\cos^2\) 用降幂公式化成一次（见 5.3 节）。
  2. 合角：把 \(\sin 2x\)、\(\cos 2x\) 用辅助角公式合成一个正弦（见 5.4 节）。
  3. 读性质：化成 \(y=A\sin(\omega x+\varphi)+B\) 之后，周期、单调区间、最值全部可以直读。

口诀：先降幂，再合角，最后读性质。这三步是固定的，看到这类题就照做。

真题 1 · 2016 北京卷（文）

已知函数 \(f(x)=2\sin\omega x\cos\omega x+\cos 2\omega x\)（\(\omega>0\)）的最小正周期为 \(\pi\)。

（1）求 \(\omega\) 的值；

（2）求 \(f(x)\) 的单调递增区间。

解析

（1）第一步：化简。第一项用二倍角公式 \(\sin 2\theta=2\sin\theta\cos\theta\)（取 \(\theta=\omega x\)）：

\[ 2\sin\omega x\cos\omega x=\sin 2\omega x \]

所以：

\[ f(x)=\sin 2\omega x+\cos 2\omega x \]

第二步：用辅助角公式合成。这里 \(a=1\)、\(b=1\)，所以 \(\sqrt{a^2+b^2}=\sqrt2\)：

\[ f(x)=\sqrt2\left(\frac{\sqrt2}{2}\sin 2\omega x+\frac{\sqrt2}{2}\cos 2\omega x\right)=\sqrt2\sin\left(2\omega x+\frac{\pi}{4}\right) \]

（因为 \(\cos\dfrac{\pi}{4}=\sin\dfrac{\pi}{4}=\dfrac{\sqrt2}{2}\)，符合辅助角公式里 \(\varphi=\dfrac{\pi}{4}\)。）

第三步：用周期条件求 \(\omega\)。对 \(y=A\sin(\omega_0 x+\varphi)\)，最小正周期是 \(T=\dfrac{2\pi}{|\omega_0|}\)。这里 \(\omega_0=2\omega\)，所以：

\[ T=\frac{2\pi}{2\omega}=\frac{\pi}{\omega} \]

由题意 \(T=\pi\)：

\[ \frac{\pi}{\omega}=\pi \quad\Longrightarrow\quad \boxed{\ \omega=1\ } \]

（2）第一步：写出 \(\omega=1\) 时的函数。

\[ f(x)=\sqrt2\sin\left(2x+\frac{\pi}{4}\right) \]

第二步：用正弦函数的单调性列不等式。\(\sin u\) 的递增区间是 \(\left[-\dfrac{\pi}{2}+2k\pi,\ \dfrac{\pi}{2}+2k\pi\right]\)。令 \(u=2x+\dfrac{\pi}{4}\)：

\[ -\frac{\pi}{2}+2k\pi\le 2x+\frac{\pi}{4}\le\frac{\pi}{2}+2k\pi \]

第三步：解出 \(x\)。三个部分同时减去 \(\dfrac{\pi}{4}\)：

\[ -\frac{3\pi}{4}+2k\pi\le 2x\le\frac{\pi}{4}+2k\pi \]

再同时除以 2：

\[ -\frac{3\pi}{8}+k\pi\le x\le\frac{\pi}{8}+k\pi \]
\[ \boxed{\ f(x)\text{ 的单调递增区间为}\left[-\frac{3\pi}{8}+k\pi,\ \frac{\pi}{8}+k\pi\right],\ k\in\mathbb{Z}\ } \]

验算：取 \(k=0\)，得区间 \(\left[-\dfrac{3\pi}{8},\dfrac{\pi}{8}\right]\)。取其中点 \(x=-\dfrac{\pi}{8}\)，则 \(u=2\left(-\dfrac{\pi}{8}\right)+\dfrac{\pi}{4}=0\)，此时 \(\sin u=0\)，位于递增段的中间位置 ✓ 合理。

提分要点
  • 第一步永远是化简。看到 \(2\sin\theta\cos\theta\) 立刻换成 \(\sin 2\theta\)；看到 \(\sin^2\theta\)、\(\cos^2\theta\) 立刻降幂。
  • 辅助角公式要熟练：\(a\sin\theta+b\cos\theta=\sqrt{a^2+b^2}\sin(\theta+\varphi)\)。本题 \(a=b=1\) 是最简单的情形。
  • 求单调区间时，"\(2x+\frac{\pi}{4}\)"是一个整体。先把整个区间解出来，再解 \(x\)。不要漏掉 \(k\in\mathbb{Z}\)。
  • 周期公式里用的是"\(x\) 的系数"（本题是 \(2\omega\)），不要漏乘 \(\omega\)。
真题 2 · 2018 北京卷（文）

已知函数 \(f(x)=\sin^{2}x+\sqrt3\sin x\cos x\)。

（1）求 \(f(x)\) 的最小正周期；

（2）若 \(f(x)\) 在区间 \(\left[-\dfrac{\pi}{3},m\right]\) 上的最大值为 \(\dfrac32\)，求 \(m\) 的最小值。

解析

（1）第一步：降幂 + 合角。

\(\sin^2x\) 用降幂公式（见 5.3 节）：

\[ \sin^{2}x=\frac{1-\cos 2x}{2} \]

\(\sqrt3\sin x\cos x\) 用二倍角公式：

\[ \sqrt3\sin x\cos x=\frac{\sqrt3}{2}\cdot2\sin x\cos x=\frac{\sqrt3}{2}\sin 2x \]

所以：

\[ f(x)=\frac{1-\cos 2x}{2}+\frac{\sqrt3}{2}\sin 2x=\frac12+\left(\frac{\sqrt3}{2}\sin 2x-\frac12\cos 2x\right) \]

第二步：对括号里的部分用辅助角公式。这里 \(a=\dfrac{\sqrt3}{2}\)、\(b=-\dfrac12\)，所以：

\[ \sqrt{a^{2}+b^{2}}=\sqrt{\frac34+\frac14}=1 \]

由 \(\cos\varphi=\dfrac{\sqrt3}{2}\)、\(\sin\varphi=-\dfrac12\) 得 \(\varphi=-\dfrac{\pi}{6}\)，于是：

\[ f(x)=\frac12+\sin\left(2x-\frac{\pi}{6}\right) \]

第三步：读周期。\(x\) 的系数是 2，所以：

\[ T=\frac{2\pi}{2}=\boxed{\pi} \]

（2）第一步：先看 \(f(x)\) 的最大值是多少。由化简结果，因为 \(\sin\left(2x-\dfrac{\pi}{6}\right)\le1\)，所以：

\[ f(x)\le\frac12+1=\frac32 \]

题目要求区间上的最大值恰好是 \(\dfrac32\)，也就是要求区间内必须存在使 \(\sin\) 取到 1 的点。

第二步：求出使 \(\sin\left(2x-\dfrac{\pi}{6}\right)=1\) 的 \(x\)。

\[ 2x-\frac{\pi}{6}=\frac{\pi}{2}+2k\pi \quad\Longrightarrow\quad 2x=\frac{2\pi}{3}+2k\pi \quad\Longrightarrow\quad x=\frac{\pi}{3}+k\pi \]

所以所有"峰值点"是 \(x=\dots,-\dfrac{2\pi}{3},\dfrac{\pi}{3},\dfrac{4\pi}{3},\dots\)

第三步：找区间左端点右侧的第一个峰值点。区间是 \(\left[-\dfrac{\pi}{3},\ m\right]\)，左端点是 \(-\dfrac{\pi}{3}\approx-1.047\)。

峰值点中，\(-\dfrac{2\pi}{3}\approx-2.094\) 在左端点左侧；\(\dfrac{\pi}{3}\approx1.047\) 在左端点右侧。

所以要让区间内出现峰值点，必须有：

\[ m\ge\frac{\pi}{3} \]

第四步：验证 \(m=\dfrac{\pi}{3}\) 时确实取到最大值。此时 \(x=\dfrac{\pi}{3}\) 恰好在区间右端点上，且

\[ f\left(\frac{\pi}{3}\right)=\frac12+\sin\left(2\cdot\frac{\pi}{3}-\frac{\pi}{6}\right)=\frac12+\sin\frac{\pi}{2}=\frac12+1=\frac32 \]

最大值确实等于 \(\dfrac32\) ✓

\[ \boxed{\ m\text{ 的最小值为 }\frac{\pi}{3}\ } \]
提分要点
  • 第（2）问的思路："最大值等于某个值" ⟹ "区间内存在使函数取到该值的点"。先算出 \(f\) 的最大值是多少（这里是 \(\dfrac32\)），再看区间里能不能取到。
  • 求峰值点 \(x\) 时，把 \(2x-\dfrac{\pi}{6}\) 整体设为 \(\dfrac{\pi}{2}+2k\pi\)。解出的 \(x=\dfrac{\pi}{3}+k\pi\) 是一串等间隔的点，然后找"左端点右侧第一个"。
  • 本题的关键是看清左端点 \(-\dfrac{\pi}{3}\) 的位置：它右侧的第一个峰值点是 \(\dfrac{\pi}{3}\)，所以 \(m\) 至少要等于 \(\dfrac{\pi}{3}\)。
  • 辅助角公式里 \(b=-\dfrac12\) 是负数，\(\varphi=-\dfrac{\pi}{6}\)。不要因为怕负号就把它当成正的（见 5.4 节的提醒）。

8.2　题型二：解三角形——求角

题型特征与解题套路

特征：给出一个含边和角的等式，要求某个角。

两条路（看等式的形式选）：

  • 统一成角：用正弦定理 \(a=2R\sin A\) 把边换成 \(\sin\)，得到纯角的关系式。适用于等式中"边角的次数相同"的情况。
  • 统一成边：用余弦定理 \(\cos A=\dfrac{b^2+c^2-a^2}{2bc}\) 把角换成边。适用于等式里有 \(\cos\) 且有平方项的情况。

常用关系：\(A+B+C=\pi\)，所以 \(\sin(A+B)=\sin C\)、\(\cos(A+B)=-\cos C\)（见 6.4 节）。

真题 3 · 2019 全国III卷（理）

\(\triangle ABC\) 的内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)。已知 \(a\sin\dfrac{A+C}{2}=b\sin A\)。

（1）求 \(B\)；

（2）若 \(\triangle ABC\) 为锐角三角形，且 \(c=1\)，求 \(\triangle ABC\) 面积的取值范围。

解析

（1）第一步：把 \(\dfrac{A+C}{2}\) 化成含 \(B\) 的式子。因为 \(A+B+C=\pi\)，所以 \(A+C=\pi-B\)，于是：

\[ \frac{A+C}{2}=\frac{\pi-B}{2}=\frac{\pi}{2}-\frac{B}{2} \]

用诱导公式：

\[ \sin\frac{A+C}{2}=\sin\left(\frac{\pi}{2}-\frac{B}{2}\right)=\cos\frac{B}{2} \]

所以条件化为：

\[ a\cos\frac{B}{2}=b\sin A \tag{①} \]

第二步：用正弦定理把边换成角。由 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=2R\)，得 \(a=2R\sin A\)、\(b=2R\sin B\)。代入①：

\[ 2R\sin A\cos\frac{B}{2}=2R\sin B\sin A \]

因为 \(A\in(0,\pi)\)，所以 \(\sin A\ne0\)，两边约去 \(2R\sin A\)（\(R>0\)）：

\[ \cos\frac{B}{2}=\sin B \]

第三步：用二倍角公式解出 \(B\)。\(\sin B=2\sin\dfrac{B}{2}\cos\dfrac{B}{2}\)：

\[ \cos\frac{B}{2}=2\sin\frac{B}{2}\cos\frac{B}{2} \]

因为 \(B\in(0,\pi)\)，所以 \(\dfrac{B}{2}\in\left(0,\dfrac{\pi}{2}\right)\)，从而 \(\cos\dfrac{B}{2}\ne0\)。两边约去：

\[ 1=2\sin\frac{B}{2} \quad\Longrightarrow\quad \sin\frac{B}{2}=\frac12 \]

因为 \(\dfrac{B}{2}\in\left(0,\dfrac{\pi}{2}\right)\)，所以 \(\dfrac{B}{2}=\dfrac{\pi}{6}\)，即：

\[ \boxed{\ B=\frac{\pi}{3}=60^{\circ}\ } \]

（2）第一步：用正弦定理把面积表示成关于 \(C\) 的式子。已知 \(B=\dfrac{\pi}{3}\)、\(c=1\)。

由正弦定理 \(\dfrac{a}{\sin A}=\dfrac{c}{\sin C}=\dfrac{1}{\sin C}\)，得：

\[ a=\frac{\sin A}{\sin C} \]

三角形面积：

\[ S=\frac12 ac\sin B=\frac12\cdot\frac{\sin A}{\sin C}\cdot1\cdot\frac{\sqrt3}{2}=\frac{\sqrt3}{4}\cdot\frac{\sin A}{\sin C} \]

第二步：把 \(A\) 换成 \(C\)。因为 \(A+C=\pi-B=\dfrac{2\pi}{3}\)，所以 \(A=\dfrac{2\pi}{3}-C\)，于是：

\[ \begin{aligned} \sin A &= \sin\left(\frac{2\pi}{3}-C\right)=\sin\frac{2\pi}{3}\cos C-\cos\frac{2\pi}{3}\sin C \\ &= \frac{\sqrt3}{2}\cos C+\frac12\sin C \end{aligned} \]

代入面积式：

\[ S=\frac{\sqrt3}{4}\cdot\frac{\frac{\sqrt3}{2}\cos C+\frac12\sin C}{\sin C}=\frac{\sqrt3}{4}\left(\frac{\sqrt3}{2}\cdot\frac{\cos C}{\sin C}+\frac12\right)=\frac38\cot C+\frac{\sqrt3}{8} \]

第三步：确定 \(C\) 的范围。"锐角三角形"意味着三个角都小于 \(\dfrac{\pi}{2}\)：

  • \(B=\dfrac{\pi}{3}<\dfrac{\pi}{2}\) ✓ 自动满足；
  • \(A=\dfrac{2\pi}{3}-C<\dfrac{\pi}{2}\ \Longrightarrow\ C>\dfrac{2\pi}{3}-\dfrac{\pi}{2}=\dfrac{\pi}{6}\)；
  • \(C<\dfrac{\pi}{2}\)。
\[ C\in\left(\frac{\pi}{6},\ \frac{\pi}{2}\right) \]

第四步：求 \(\cot C\) 的范围。\(\cot C=\dfrac{\cos C}{\sin C}\) 在 \(\left(0,\pi\right)\) 上是单调递减的（这也可以由 \(\cot C=\dfrac{1}{\tan C}\) 且 \(\tan C\) 递增看出）。

计算两端：

\[ \cot\frac{\pi}{6}=\sqrt3,\qquad \cot\frac{\pi}{2}=0 \]

所以当 \(C\in\left(\dfrac{\pi}{6},\dfrac{\pi}{2}\right)\) 时：

\[ \cot C\in\left(0,\ \sqrt3\right) \]

第五步：求 \(S\) 的范围。

\[ S=\frac38\cot C+\frac{\sqrt3}{8}\in\left(\frac38\times0+\frac{\sqrt3}{8},\ \frac38\times\sqrt3+\frac{\sqrt3}{8}\right)=\left(\frac{\sqrt3}{8},\ \frac{\sqrt3}{2}\right) \]
\[ \boxed{\ S\in\left(\frac{\sqrt3}{8},\ \frac{\sqrt3}{2}\right)\ } \]

验算（取特殊值）：取 \(C=\dfrac{\pi}{3}\)（在区间内），则 \(A=\dfrac{\pi}{3}\)，三角形是等边三角形，\(a=c=1\)，

\[ S=\frac12\times1\times1\times\sin\frac{\pi}{3}=\frac{\sqrt3}{4}\approx0.433 \]

而区间 \(\left(\dfrac{\sqrt3}{8},\dfrac{\sqrt3}{2}\right)\approx(0.217,\ 0.866)\) 包含 \(0.433\) ✓

提分要点
  • 看到 \(\sin\dfrac{A+C}{2}\) 要立刻想到 \(A+C=\pi-B\)，把它化成 \(\cos\dfrac{B}{2}\)。这是解三角形的常用转化。
  • "锐角三角形"是求范围的关键条件，要翻译成三个不等式。本题由 \(A<\dfrac{\pi}{2}\) 得到 \(C>\dfrac{\pi}{6}\)，这一步最容易漏。
  • 求面积范围的通用思路：用正弦定理把 \(S\) 表示成某一个角的函数（本题是 \(C\)），再求这个角的范围，最后用单调性求 \(S\) 的范围。

真题 4 · 2024 新高考I卷

记 \(\triangle ABC\) 的内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)。已知 \(\sin C=\sqrt2\cos B\)，\(a^{2}+b^{2}-c^{2}=\sqrt2\,ab\)。

（1）求 \(B\)；

（2）若 \(\triangle ABC\) 的面积为 \(3+\sqrt3\)，求 \(c\)。

解析

（1）第一步：用余弦定理处理第二个条件。余弦定理给出 \(c^{2}=a^{2}+b^{2}-2ab\cos C\)，移项得：

\[ a^{2}+b^{2}-c^{2}=2ab\cos C \]

与已知 \(a^{2}+b^{2}-c^{2}=\sqrt2\,ab\) 对比（\(ab>0\)）：

\[ 2ab\cos C=\sqrt2\,ab \quad\Longrightarrow\quad \cos C=\frac{\sqrt2}{2} \]

第二步：确定 \(C\)。因为 \(C\in(0,\pi)\)，而 \(\cos C=\dfrac{\sqrt2}{2}>0\)，所以 \(C\) 是锐角：

\[ C=\frac{\pi}{4},\qquad \sin C=\frac{\sqrt2}{2} \]

第三步：用第一个条件求 \(B\)。

\[ \sin C=\sqrt2\cos B \quad\Longrightarrow\quad \frac{\sqrt2}{2}=\sqrt2\cos B \quad\Longrightarrow\quad \cos B=\frac12 \]

因为 \(B\in(0,\pi)\)，所以：

\[ \boxed{\ B=\frac{\pi}{3}\ } \]

合理性检查：\(B+C=\dfrac{\pi}{3}+\dfrac{\pi}{4}=\dfrac{7\pi}{12}<\pi\) ✓ 三角形存在。

（2）第一步：求 \(A\)。

\[ A=\pi-B-C=\pi-\frac{\pi}{3}-\frac{\pi}{4}=\frac{5\pi}{12} \]

第二步：用正弦定理把 \(a\)、\(b\) 用 \(c\) 表示。设 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}\)，则：

\[ a=\frac{c\sin A}{\sin C},\qquad b=\frac{c\sin B}{\sin C} \]

先算 \(\sin\dfrac{5\pi}{12}\)（用 \(\dfrac{5\pi}{12}=\dfrac{\pi}{4}+\dfrac{\pi}{6}\)）：

\[ \sin\frac{5\pi}{12}=\sin\left(\frac{\pi}{4}+\frac{\pi}{6}\right)=\sin\frac{\pi}{4}\cos\frac{\pi}{6}+\cos\frac{\pi}{4}\sin\frac{\pi}{6}=\frac{\sqrt2}{2}\cdot\frac{\sqrt3}{2}+\frac{\sqrt2}{2}\cdot\frac12=\frac{\sqrt6+\sqrt2}{4} \]

代入：

\[ a=c\cdot\frac{\frac{\sqrt6+\sqrt2}{4}}{\frac{\sqrt2}{2}}=c\cdot\frac{\sqrt6+\sqrt2}{4}\cdot\frac{2}{\sqrt2}=c\cdot\frac{\sqrt6+\sqrt2}{2\sqrt2}=c\cdot\frac{\sqrt3+1}{2} \]

（最后一步：\(\dfrac{\sqrt6}{2\sqrt2}=\dfrac{\sqrt3}{2}\)、\(\dfrac{\sqrt2}{2\sqrt2}=\dfrac12\)。）

\[ b=c\cdot\frac{\frac{\sqrt3}{2}}{\frac{\sqrt2}{2}}=c\cdot\frac{\sqrt3}{\sqrt2}=c\cdot\frac{\sqrt6}{2} \]

第三步：用面积条件列方程。

\[ S=\frac12 ab\sin C=\frac12\cdot c\cdot\frac{\sqrt3+1}{2}\cdot c\cdot\frac{\sqrt6}{2}\cdot\frac{\sqrt2}{2} \]

把常数部分整理：

\[ \frac12\cdot\frac{\sqrt3+1}{2}\cdot\frac{\sqrt6}{2}\cdot\frac{\sqrt2}{2}=\frac{(\sqrt3+1)\sqrt{12}}{16}=\frac{(\sqrt3+1)\cdot2\sqrt3}{16}=\frac{3+\sqrt3}{8} \]

所以：

\[ S=\frac{3+\sqrt3}{8}\,c^{2} \]

由 \(S=3+\sqrt3\)：

\[ \frac{3+\sqrt3}{8}c^{2}=3+\sqrt3 \quad\Longrightarrow\quad c^{2}=8 \]

第四步：取正根。因为 \(c\) 是边长，必须为正：

\[ \boxed{\ c=2\sqrt2\ } \]

验算：\(c=2\sqrt2\approx2.828\)，则 \(a=\dfrac{\sqrt3+1}{2}\times2\sqrt2=(\sqrt3+1)\sqrt2\approx3.864\)，\(b=\dfrac{\sqrt6}{2}\times2\sqrt2=\sqrt{12}=2\sqrt3\approx3.464\)。

用余弦定理验算 \(B\)：\(\cos B=\dfrac{a^2+c^2-b^2}{2ac}=\dfrac{14.93+8-12}{2\times3.864\times2.828}=\dfrac{10.93}{21.85}\approx0.5\) ✓

提分要点
  • 看到 \(a^2+b^2-c^2\) 要立刻联想到余弦定理。它正好等于 \(2ab\cos C\)，这是"由边的关系求角"的标准入口。
  • 本题两次用到"由等式求角"：第一次由边的关系求出 \(\cos C\)，第二次由 \(\sin C=\sqrt2\cos B\) 求出 \(\cos B\)。
  • 求 \(c\) 的通用思路：把 \(a\)、\(b\) 都用 \(c\) 表示，再代入面积条件。这样只剩一个未知数 \(c\)。
  • \(\sin\dfrac{5\pi}{12}=\dfrac{\sqrt6+\sqrt2}{4}\) 是常用值（相当于 \(\sin 75^\circ\)），建议记住。
  • 最后别忘了"边长为正"，舍去负根。

真题 5 · 2019 北京卷（理）

在 \(\triangle ABC\) 中，\(a=3\)，\(b-c=2\)，\(\cos B=-\dfrac12\)。

（1）求 \(b\)，\(c\) 的值；

（2）求 \(\sin(B-C)\) 的值。

解析

（1）第一步：用余弦定理建立方程。角 \(B\) 的对边是 \(b\)，由余弦定理：

\[ b^{2}=a^{2}+c^{2}-2ac\cos B \]

代入 \(a=3\)、\(\cos B=-\dfrac12\)：

\[ b^{2}=9+c^{2}-2\times3\times c\times\left(-\frac12\right)=9+c^{2}+3c \tag{①} \]

第二步：用 \(b-c=2\) 消去一个未知数。由 \(b-c=2\) 得 \(b=c+2\)，代入①：

\[ (c+2)^{2}=9+c^{2}+3c \]
\[ c^{2}+4c+4=9+c^{2}+3c \]

两边消去 \(c^2\)：

\[ 4c+4=9+3c \quad\Longrightarrow\quad c=5 \]

所以 \(b=c+2=7\)。

\[ \boxed{\ b=7,\quad c=5\ } \]

（2）第一步：先求出 \(\sin B\)。因为 \(\cos B=-\dfrac12<0\)，所以 \(B\) 是钝角，\(B\in\left(\dfrac{\pi}{2},\pi\right)\)，从而 \(\sin B>0\)：

\[ \sin B=\sqrt{1-\cos^{2}B}=\sqrt{1-\frac14}=\frac{\sqrt3}{2} \]

第二步：用正弦定理求 \(\sin C\)。由 \(\dfrac{b}{\sin B}=\dfrac{c}{\sin C}\)：

\[ \frac{7}{\frac{\sqrt3}{2}}=\frac{5}{\sin C} \quad\Longrightarrow\quad \frac{14}{\sqrt3}=\frac{5}{\sin C} \quad\Longrightarrow\quad \sin C=\frac{5\sqrt3}{14} \]

第三步：确定 \(\cos C\) 的符号。因为 \(b=7>c=5\)，由"大边对大角"得 \(B>C\)。而 \(B\) 是钝角，所以 \(C\) 一定是锐角，因此 \(\cos C>0\)：

\[ \cos C=\sqrt{1-\sin^{2}C}=\sqrt{1-\frac{75}{196}}=\sqrt{\frac{121}{196}}=\frac{11}{14} \]

第四步：用差角公式求 \(\sin(B-C)\)。

\[ \sin(B-C)=\sin B\cos C-\cos B\sin C \]
\[ =\frac{\sqrt3}{2}\cdot\frac{11}{14}-\left(-\frac12\right)\cdot\frac{5\sqrt3}{14}=\frac{11\sqrt3}{28}+\frac{5\sqrt3}{28}=\frac{16\sqrt3}{28} \]
\[ \boxed{\ \sin(B-C)=\frac{4\sqrt3}{7}\ } \]

验算（检查 \(\cos C\) 的符号判断）：由余弦定理算 \(C\)：

\[ \cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=\frac{9+49-25}{2\times3\times7}=\frac{33}{42}=\frac{11}{14}>0 \quad\checkmark \]

与上面的判断一致 ✓

提分要点
  • 已知"一边 + 另两边之差 + 一个角"，标准做法是用余弦定理。本题把 \(b=c+2\) 代入余弦定理，得到关于 \(c\) 的一次方程，非常干净。
  • \(\cos B<0\) 说明 \(B\) 是钝角，\(\sin B\) 取正。这一步是常识但必须写。
  • 求 \(\cos C\) 时要判断符号。方法有两个：① 用"大边对大角"（\(b>c\) ⟹ \(B>C\)，而 \(B\) 是钝角，所以 \(C\) 是锐角）；② 直接用余弦定理算（本题验算用的就是这一招）。两种方法都要会。
  • \(\sin(B-C)\) 用差角公式展开，注意 \(\cos B\) 是负数，"减负得正"这一步最容易错。
真题 6 · 2021 新高考I卷　★★

记 \(\triangle ABC\) 的内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)。已知 \(b^{2}=ac\)，点 \(D\) 在边 \(AC\) 上，且 \(BD\sin\angle ABC=a\sin C\)。

（1）证明：\(BD=b\)；

（2）若 \(AD=2DC\)，求 \(\cos\angle ABC\)。

解析

（1）第一步：把 \(a\sin C\) 用正弦定理转化。由正弦定理 \(\dfrac{a}{\sin A}=\dfrac{c}{\sin C}=2R\)，得 \(\sin A=\dfrac{a}{2R}\)、\(\sin C=\dfrac{c}{2R}\)。

所以：

\[ a\sin C=a\cdot\frac{c}{2R}=\frac{ac}{2R} \]

同理 \(\sin B=\dfrac{b}{2R}\)。

第二步：代入已知条件。

\[ BD\cdot\frac{b}{2R}=\frac{ac}{2R} \quad\Longrightarrow\quad BD\cdot b=ac \]

第三步：用 \(b^2=ac\) 得结论。把 \(ac=b^2\) 代入：

\[ BD\cdot b=b^{2} \quad\Longrightarrow\quad BD=b \quad\checkmark \]

（因为 \(b>0\)，可以两边约去 \(b\)。）∎

（2）第一步：把已知条件翻译成边长。\(AC=b\)，且 \(AD=2DC\)，所以：

\[ AD=\frac{2}{3}b,\qquad DC=\frac13 b \]

又由（1）\(BD=b\)。记 \(u=\cos\angle ADB\)（即 \(\cos\angle BDC\) 的相反数，因为 \(D\) 在 \(AC\) 上，\(\angle ADB+\angle BDC=\pi\)）。

第二步：在两个小三角形里各用一次余弦定理。

在 \(\triangle ABD\) 中（\(AB=c\)，\(AD=\dfrac{2b}{3}\)，\(BD=b\)，夹角是 \(\angle ADB\)）：

\[ c^{2}=AD^{2}+BD^{2}-2\cdot AD\cdot BD\cos u=\frac{4b^{2}}{9}+b^{2}-\frac{4b^{2}}{3}u=\frac{13b^{2}}{9}-\frac{4b^{2}}{3}u \tag{①} \]

在 \(\triangle BDC\) 中（\(BC=a\)，\(DC=\dfrac b3\)，\(BD=b\)，夹角是 \(\angle BDC=\pi-\angle ADB\)，其余弦为 \(-\cos u\)）：

\[ a^{2}=DC^{2}+BD^{2}-2\cdot DC\cdot BD\cos(\pi-u)=\frac{b^{2}}{9}+b^{2}+\frac{2b^{2}}{3}u=\frac{10b^{2}}{9}+\frac{2b^{2}}{3}u \tag{②} \]

第三步：用 \(b^2=ac\) 建立方程。由②×①并利用 \(ac=b^2\)（两边平方得 \(a^2c^2=b^4\)）：

\[ \left(\frac{10b^{2}}{9}+\frac{2b^{2}}{3}u\right)\left(\frac{13b^{2}}{9}-\frac{4b^{2}}{3}u\right)=b^{4} \]

两边除以 \(b^4\)（\(b>0\)）：

\[ \left(\frac{10}{9}+\frac{2u}{3}\right)\left(\frac{13}{9}-\frac{4u}{3}\right)=1 \]

展开左边：

\[ \frac{130}{81}-\frac{40u}{27}+\frac{26u}{27}-\frac{8u^{2}}{9}=1 \]
\[ \frac{130}{81}-\frac{14u}{27}-\frac{8u^{2}}{9}=1 \]

两边乘 81：

\[ 130-42u-72u^{2}=81 \quad\Longrightarrow\quad 72u^{2}+42u-49=0 \]

第四步：解这个一元二次方程。

\[ u=\frac{-42\pm\sqrt{42^{2}-4\times72\times(-49)}}{2\times72}=\frac{-42\pm\sqrt{1764+14112}}{144}=\frac{-42\pm\sqrt{15876}}{144} \]

因为 \(126^{2}=15876\)，所以 \(\sqrt{15876}=126\)：

\[ u=\frac{-42\pm126}{144} \]

取正号：\(u=\dfrac{84}{144}=\dfrac{7}{12}\)；取负号：\(u=-\dfrac{168}{144}=-\dfrac76\)。

因为 \(|\cos\theta|\le1\)，所以 \(u=-\dfrac76\) 舍去。故

\[ \cos\angle ADB=\frac{7}{12} \]

第五步：求 \(\cos\angle ABC\)。在 \(\triangle ABC\) 中用余弦定理：

\[ \cos\angle ABC=\frac{a^{2}+c^{2}-b^{2}}{2ac} \]

由①②相加：

\[ a^{2}+c^{2}=\frac{13b^{2}}{9}-\frac{4b^{2}}{3}u+\frac{10b^{2}}{9}+\frac{2b^{2}}{3}u=\frac{23b^{2}}{9}-\frac{2b^{2}}{3}u \]

所以：

\[ a^{2}+c^{2}-b^{2}=\frac{23b^{2}}{9}-b^{2}-\frac{2b^{2}}{3}u=\frac{14b^{2}}{9}-\frac{2b^{2}}{3}u \]

又 \(ac=b^2\)，所以 \(2ac=2b^2\)：

\[ \cos\angle ABC=\frac{\frac{14b^{2}}{9}-\frac{2b^{2}}{3}u}{2b^{2}}=\frac{7}{9}-\frac{u}{3} \]

代入 \(u=\dfrac{7}{12}\)：

\[ \cos\angle ABC=\frac79-\frac{1}{3}\times\frac{7}{12}=\frac79-\frac{7}{36}=\frac{28}{36}-\frac{7}{36}=\frac{21}{36} \]
\[ \boxed{\ \cos\angle ABC=\frac{7}{12}\ } \]
提分要点
  • 第（1）问的关键：把 \(a\sin C\) 用 \(2R\) 表示。由正弦定理 \(a=2R\sin A\)、\(\sin C=\dfrac{c}{2R}\)，所以 \(a\sin C=\dfrac{ac}{2R}\)。这个"用 \(2R\) 统一"的手法在解三角形里很常用。
  • 第（2）问的难点是"两个未知数 \(a\)、\(c\)"，要靠 \(b^2=ac\) 消掉。方法是把 \(a^2\)、\(c^2\) 用 \(b\) 和 \(u=\cos\angle ADB\) 表示，再代入 \(a^2c^2=b^4\)。
  • 注意 \(\angle ADB+\angle BDC=\pi\)，所以它们的余弦互为相反数。这是"点在边上"类问题的通用关系。
  • 解出 \(u=\dfrac{7}{12}\) 或 \(-\dfrac76\) 后，必须用 \(|\cos\theta|\le1\) 舍去不合理的根。
  • 最后求 \(\cos\angle ABC\) 时，把 \(a^2+c^2\) 整体算出来，比分别求 \(a\)、\(c\) 简单得多。

8.4　题型四：解三角形——范围、最值与结构不良题

题型特征与解题套路

特征：求某个量的取值范围（面积范围、周长范围、三角函数式的范围）。

套路（三步走）：

  1. 用一个角（或一条边）表示所有量。通常用正弦定理把边都换成角，或者用余弦定理把角换成边。
  2. 确定这个角（或边）的范围。范围往往来自"锐角三角形"、"A 为钝角"这类条件，或者来自三角形不等式。
  3. 用单调性或基本不等式求最值。

★ 最容易漏的一步是第 2 步——把"锐角三角形"翻译成三个不等式，这一步直接决定答案的端点是开还是闭。

真题 7 · 2022 新高考I卷　★★

记 \(\triangle ABC\) 的内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)，已知 \(\dfrac{\cos A}{1+\sin A}=\dfrac{\sin 2B}{1+\cos 2B}\)。

（1）若 \(C=\dfrac{2\pi}{3}\)，求 \(B\)；

（2）求 \(\dfrac{a^{2}+b^{2}}{c^{2}}\) 的最小值。

解析

（1）第一步：化简右边的式子。用二倍角公式：

\[ \sin 2B=2\sin B\cos B,\qquad 1+\cos 2B=1+(2\cos^{2}B-1)=2\cos^{2}B \]

所以：

\[ \frac{\sin 2B}{1+\cos 2B}=\frac{2\sin B\cos B}{2\cos^{2}B}=\frac{\sin B}{\cos B}=\tan B \]

（这里要求 \(\cos B\ne0\)，即 \(B\ne\dfrac{\pi}{2}\)；由后面的结果会看到 \(B<\dfrac{\pi}{2}\)，所以这个化简是合法的。）

第二步：化简左边的式子。左边的结构让人联想到半角公式（见 5.5 节）：

\[ \tan\left(\frac{\pi}{4}-\frac{A}{2}\right)=\frac{1-\sin A}{\cos A} \]

把它与左边对照，会发现左边正好是右边取倒数，所以更直接的做法是交叉相乘：

\[ \cos A\cos B=\sin B(1+\sin A)=\sin B+\sin A\sin B \]

移项：

\[ \cos A\cos B-\sin A\sin B=\sin B \]

第三步：认出左边是差角余弦公式。由 \(\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta\)：

\[ \cos(A+B)=\sin B \]

因为 \(A+B=\pi-C\)，所以 \(\cos(A+B)=\cos(\pi-C)=-\cos C\)：

\[ -\cos C=\sin B \tag{①} \]

第四步：代入 \(C=\dfrac{2\pi}{3}\)。

\[ \sin B=-\cos\frac{2\pi}{3}=-\left(-\frac12\right)=\frac12 \]

因为 \(A+B=\pi-C=\dfrac{\pi}{3}\)，所以 \(0<B<\dfrac{\pi}{3}<\dfrac{\pi}{2}\)，从而 \(B\) 是锐角：

\[ \boxed{\ B=\frac{\pi}{6}\ } \]

（2）第一步：由①确定 \(B\) 与 \(C\) 的关系。由①，\(\sin B=-\cos C>0\)（因为 \(\sin B>0\)），所以 \(\cos C<0\)，即 \(C\in\left(\dfrac{\pi}{2},\pi\right)\)。

用诱导公式：

\[ \sin B=-\cos C=\sin\left(C-\frac{\pi}{2}\right) \]

现在要由 \(\sin B=\sin\left(C-\dfrac{\pi}{2}\right)\) 反解 \(B\)。不能直接"两边去 \(\sin\)"，因为满足条件的 \(B\) 有两个候选：

\[ B=C-\frac{\pi}{2} \qquad\text{或}\qquad B=\pi-\left(C-\frac{\pi}{2}\right)=\frac{3\pi}{2}-C \]

用内角和排除第二个。若 \(B=\dfrac{3\pi}{2}-C\)，则

\[ A=\pi-B-C=\pi-\left(\frac{3\pi}{2}-C\right)-C=-\frac{\pi}{2}<0 \]

与 \(A>0\) 矛盾，所以第二个候选不成立。故只能取

\[ B=C-\frac{\pi}{2} \quad\Longrightarrow\quad C=\frac{\pi}{2}+B \]

第二步：确定 \(B\) 的范围。

\[ A=\pi-B-C=\pi-B-\left(\frac{\pi}{2}+B\right)=\frac{\pi}{2}-2B \]

因为 \(A>0\)，所以 \(\dfrac{\pi}{2}-2B>0\)，即 \(B<\dfrac{\pi}{4}\)。又 \(B>0\)，所以：

\[ B\in\left(0,\ \frac{\pi}{4}\right) \]

第三步：用正弦定理把目标式化成关于 \(B\) 的式子。由 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}\)，设比值为 \(k\)，则 \(a=k\sin A\)、\(b=k\sin B\)、\(c=k\sin C\)。所以：

\[ \frac{a^{2}+b^{2}}{c^{2}}=\frac{\sin^{2}A+\sin^{2}B}{\sin^{2}C} \]

把 \(A=\dfrac{\pi}{2}-2B\)、\(C=\dfrac{\pi}{2}+B\) 代入：

\[ \sin A=\sin\left(\frac{\pi}{2}-2B\right)=\cos 2B,\qquad \sin C=\sin\left(\frac{\pi}{2}+B\right)=\cos B \]

所以：

\[ \frac{a^{2}+b^{2}}{c^{2}}=\frac{\cos^{2}2B+\sin^{2}B}{\cos^{2}B} \]

第四步：换元。令 \(s=\sin^{2}B\)，则 \(\cos^{2}B=1-s\)，且

\[ \cos 2B=1-2\sin^{2}B=1-2s \quad\Longrightarrow\quad \cos^{2}2B=(1-2s)^{2} \]

代入：

\[ \frac{a^{2}+b^{2}}{c^{2}}=\frac{(1-2s)^{2}+s}{1-s}=\frac{1-4s+4s^{2}+s}{1-s}=\frac{4s^{2}-3s+1}{1-s} \]

由 \(B\in\left(0,\dfrac{\pi}{4}\right)\) 得 \(s\in\left(0,\dfrac12\right)\)。

第五步：求最小值。设 \(F(s)=\dfrac{4s^{2}-3s+1}{1-s}\)，\(s\in\left(0,\dfrac12\right)\)。用商法则求导：

\[ F'(s)=\frac{(8s-3)(1-s)-(4s^{2}-3s+1)\cdot(-1)}{(1-s)^{2}} \]

分子整理：

\[ (8s-3)(1-s)+4s^{2}-3s+1=8s-8s^{2}-3+3s+4s^{2}-3s+1=-4s^{2}+8s-2 \]

所以：

\[ F'(s)=\frac{-4s^{2}+8s-2}{(1-s)^{2}}=\frac{-2(2s^{2}-4s+1)}{(1-s)^{2}} \]

令 \(2s^{2}-4s+1=0\)：

\[ s=\frac{4\pm\sqrt{16-8}}{4}=\frac{4\pm2\sqrt2}{4}=1\pm\frac{\sqrt2}{2} \]

在 \(\left(0,\dfrac12\right)\) 内的根是 \(s_{0}=1-\dfrac{\sqrt2}{2}\approx0.293\)。

因为分母 \((1-s)^2>0\)，所以 \(F'(s)\) 的符号由 \(-2(2s^2-4s+1)\) 决定：

  • \(s<s_0\) 时 \(2s^2-4s+1>0\)（取 \(s=0\) 验：\(1>0\) ✓），故 \(F'(s)<0\)，\(F\) 递减；
  • \(s>s_0\) 时 \(F'(s)>0\)，\(F\) 递增。

所以 \(F\) 在 \(s=s_0\) 处取到最小值。

第六步：算最小值。把 \(s_0=1-\dfrac{\sqrt2}{2}\) 代入。先算 \(s_0^2\)：

\[ s_0^{2}=\left(1-\frac{\sqrt2}{2}\right)^{2}=1-\sqrt2+\frac12=\frac32-\sqrt2 \]

分子：

\[ 4s_0^{2}-3s_0+1=4\left(\frac32-\sqrt2\right)-3\left(1-\frac{\sqrt2}{2}\right)+1=6-4\sqrt2-3+\frac{3\sqrt2}{2}+1=4-\frac{5\sqrt2}{2} \]

分母：

\[ 1-s_0=\frac{\sqrt2}{2} \]

所以：

\[ F_{\min}=\frac{4-\frac{5\sqrt2}{2}}{\frac{\sqrt2}{2}}=\frac{8-5\sqrt2}{\sqrt2}=\frac{8}{\sqrt2}-5=4\sqrt2-5 \]
\[ \boxed{\ \frac{a^{2}+b^{2}}{c^{2}}\text{ 的最小值为 }4\sqrt2-5\ } \]

验算：取 \(s=\dfrac14\)（即 \(B=\dfrac{\pi}{6}\)，在区间内），则

\[ F=\frac{4\times\frac1{16}-\frac34+1}{1-\frac14}=\frac{\frac14-\frac34+1}{\frac34}=\frac{\frac12}{\frac34}=\frac23\approx0.667 \]

而 \(4\sqrt2-5\approx5.657-5=0.657<0.667\) ✓ 最小值小于该点的值，合理。

提分要点
  • 化简 \(\dfrac{\sin 2B}{1+\cos 2B}\) 是本题的突破口。它等于 \(\tan B\)，这是二倍角公式的直接应用。
  • 交叉相乘后认出 \(\cos(A+B)\) 是关键一步。这类"看起来陌生的等式"往往就是差角/和角公式的变形。
  • 由 \(\sin B=-\cos C\) 推出 \(C=\dfrac{\pi}{2}+B\) 时，要说明 \(\sin\) 的单调性，不能直接写等号。
  • 求范围的通用思路：把目标式化成关于某一个角（本题是 \(B\)）的函数，再求这个角的范围。这里用 \(\sin^2B\) 换元后变成了有理函数，便于求导。
  • 换元后一定要算出新变量的范围（本题 \(s\in\left(0,\dfrac12\right)\)），否则求最值时容易出错。
  • 最后算 \(4\sqrt2-5\) 时要细心：\(\dfrac{8-5\sqrt2}{\sqrt2}=\dfrac{8}{\sqrt2}-5=4\sqrt2-5\)。
真题 8 · 2020 浙江卷

在锐角 \(\triangle ABC\) 中，角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)，且 \(2b\sin A=\sqrt3\,a\)。

（1）求角 \(B\)；

（2）求 \(\cos A+\cos B+\cos C\) 的取值范围。

解析

（1）第一步：用正弦定理把边换成角。由 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}\)，得 \(a=\dfrac{b\sin A}{\sin B}\)。代入条件：

\[ 2b\sin A=\sqrt3\cdot\frac{b\sin A}{\sin B} \]

因为 \(b>0\)、\(A\in(0,\pi)\) 所以 \(\sin A>0\)，两边约去 \(b\sin A\)：

\[ 2=\frac{\sqrt3}{\sin B} \quad\Longrightarrow\quad \sin B=\frac{\sqrt3}{2} \]

第二步：用"锐角"确定 \(B\)。\(\sin B=\dfrac{\sqrt3}{2}\) 给出 \(B=\dfrac{\pi}{3}\) 或 \(B=\dfrac{2\pi}{3}\)。但三角形是锐角三角形，\(B<\dfrac{\pi}{2}\)，所以：

\[ \boxed{\ B=\frac{\pi}{3}\ } \]

（2）第一步：把目标式化成关于 \(A\) 的式子。因为 \(A+B+C=\pi\) 且 \(B=\dfrac{\pi}{3}\)：

\[ C=\pi-A-\frac{\pi}{3}=\frac{2\pi}{3}-A \]

所以：

\[ \cos A+\cos B+\cos C=\cos A+\frac12+\cos\left(\frac{2\pi}{3}-A\right) \]

第二步：展开 \(\cos\left(\dfrac{2\pi}{3}-A\right)\)。用差角余弦公式：

\[ \cos\left(\frac{2\pi}{3}-A\right)=\cos\frac{2\pi}{3}\cos A+\sin\frac{2\pi}{3}\sin A=-\frac12\cos A+\frac{\sqrt3}{2}\sin A \]

代入：

\[ \cos A+\frac12-\frac12\cos A+\frac{\sqrt3}{2}\sin A=\frac12+\left(\frac12\cos A+\frac{\sqrt3}{2}\sin A\right) \]

第三步：用辅助角公式合并。括号里 \(a=\dfrac12\)、\(b=\dfrac{\sqrt3}{2}\)，所以 \(\sqrt{a^2+b^2}=1\)，且 \(\cos\varphi=\dfrac12\)、\(\sin\varphi=\dfrac{\sqrt3}{2}\)，即 \(\varphi=\dfrac{\pi}{3}\)：

\[ \frac12\cos A+\frac{\sqrt3}{2}\sin A=\cos\left(A-\frac{\pi}{3}\right) \]

所以：

\[ \cos A+\cos B+\cos C=\frac12+\cos\left(A-\frac{\pi}{3}\right) \]

第四步：确定 \(A\) 的范围（关键）。"锐角三角形"要求三个角都小于 \(\dfrac{\pi}{2}\)：

  • \(B=\dfrac{\pi}{3}<\dfrac{\pi}{2}\) ✓ 自动满足；
  • \(A<\dfrac{\pi}{2}\)；
  • \(C=\dfrac{2\pi}{3}-A<\dfrac{\pi}{2}\ \Longrightarrow\ A>\dfrac{2\pi}{3}-\dfrac{\pi}{2}=\dfrac{\pi}{6}\)。
\[ A\in\left(\frac{\pi}{6},\ \frac{\pi}{2}\right) \]

所以：

\[ A-\frac{\pi}{3}\in\left(-\frac{\pi}{6},\ \frac{\pi}{6}\right) \]

第五步：求 \(\cos\left(A-\dfrac{\pi}{3}\right)\) 的范围。在这个区间上，\(\cos\) 的最大值在 \(A-\dfrac{\pi}{3}=0\) 处取到（此时 \(A=\dfrac{\pi}{3}\)，在区间内），值为 1；

两端 \(A-\dfrac{\pi}{3}=\pm\dfrac{\pi}{6}\) 处，\(\cos\left(\pm\dfrac{\pi}{6}\right)=\dfrac{\sqrt3}{2}\)。因为区间是开区间，端点取不到，所以：

\[ \cos\left(A-\frac{\pi}{3}\right)\in\left(\frac{\sqrt3}{2},\ 1\right] \]

第六步：得最终范围。

\[ \cos A+\cos B+\cos C\in\left(\frac12+\frac{\sqrt3}{2},\ \frac12+1\right]=\left(\frac{1+\sqrt3}{2},\ \frac32\right] \]
\[ \boxed{\ \cos A+\cos B+\cos C\in\left(\frac{1+\sqrt3}{2},\ \frac32\right]\ } \]

验算：取 \(A=\dfrac{\pi}{3}\)（在区间内），则 \(C=\dfrac{\pi}{3}\)，三角形是等边三角形：

\[ \cos A+\cos B+\cos C=3\times\frac12=\frac32 \]

正好是右端点（可以取到）✓

提分要点
  • "锐角三角形"必须翻译成三个不等式。本题由 \(C<\dfrac{\pi}{2}\) 得到 \(A>\dfrac{\pi}{6}\)，这是最容易漏的一步。漏了这一步，答案会写成 \(\left(\dfrac{1+\sqrt3}{2},\dfrac32\right]\) 变成 \(\left[\dfrac12+\dfrac{\sqrt3}{2},\dfrac32\right]\) 之类的错误形式。
  • 把三个角化成一个角（本题是 \(A\)）是求范围的通用手法。
  • 展开 \(\cos\left(\dfrac{2\pi}{3}-A\right)\) 后用辅助角公式合并，这是"三角式求和范围"的标准套路。
  • 注意端点的开闭：\(A=\dfrac{\pi}{3}\) 在区间内，所以最大值 \(\dfrac32\) 可以取到（闭）；而 \(A=\dfrac{\pi}{6}\)、\(A=\dfrac{\pi}{2}\) 取不到，所以下端点开。
真题 9 · 2021 新高考II卷

在 \(\triangle ABC\) 中，角 \(A\)、\(B\)、\(C\) 所对的边长分别为 \(a\)、\(b\)、\(c\)，\(b=a+1\)，\(c=a+2\)。

（1）若 \(2\sin C=3\sin A\)，求 \(\triangle ABC\) 的面积；

（2）是否存在正整数 \(a\)，使得 \(\triangle ABC\) 为钝角三角形？若存在，求出 \(a\) 的值；若不存在，说明理由。

解析

（1）第一步：用正弦定理把角的关系变成边的关系。由正弦定理 \(\dfrac{\sin C}{\sin A}=\dfrac{c}{a}\)。已知 \(2\sin C=3\sin A\)，即 \(\dfrac{\sin C}{\sin A}=\dfrac32\)，所以：

\[ \frac ca=\frac32 \]

代入 \(c=a+2\)：

\[ \frac{a+2}{a}=\frac32 \quad\Longrightarrow\quad 2a+4=3a \quad\Longrightarrow\quad a=4 \]

所以 \(b=5\)、\(c=6\)。

第二步：用余弦定理求一个角，再算面积。先用余弦定理求 \(\cos B\)：

\[ \cos B=\frac{a^{2}+c^{2}-b^{2}}{2ac}=\frac{16+36-25}{2\times4\times6}=\frac{27}{48}=\frac{9}{16} \]

所以 \(\sin B=\sqrt{1-\dfrac{81}{256}}=\sqrt{\dfrac{175}{256}}=\dfrac{5\sqrt7}{16}\)。

面积：

\[ S=\frac12 ac\sin B=\frac12\times4\times6\times\frac{5\sqrt7}{16}=12\times\frac{5\sqrt7}{16}=\frac{15\sqrt7}{4} \]
\[ \boxed{\ S=\frac{15\sqrt7}{4}\ } \]

（2）第一步：确定最大边。因为 \(c=a+2>b=a+1>a\)（\(a>0\)），所以 \(c\) 是最大边。

第二步：三角形存在的条件。三边要能构成三角形，需要 \(a+b>c\)：

\[ a+(a+1)>a+2 \quad\Longrightarrow\quad a>1 \]

因为 \(a\) 是正整数，所以 \(a\ge2\)。

第三步：钝角三角形的条件。三角形为钝角三角形，当且仅当最大边所对的角是钝角，即 \(c\) 所对的角 \(C\) 满足 \(C>\dfrac{\pi}{2}\)。

由余弦定理，\(C>\dfrac{\pi}{2}\) 等价于 \(\cos C<0\)，即：

\[ \cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}<0 \quad\Longleftrightarrow\quad c^{2}>a^{2}+b^{2} \]

代入 \(b=a+1\)、\(c=a+2\)：

\[ (a+2)^{2}>a^{2}+(a+1)^{2} \]
\[ a^{2}+4a+4>a^{2}+a^{2}+2a+1 \]
\[ 4a+4>a^{2}+2a+1 \quad\Longrightarrow\quad 0>a^{2}-2a-3 \quad\Longrightarrow\quad (a-3)(a+1)<0 \]

所以 \(-1<a<3\)。

第四步：取正整数解。结合 \(a\ge2\)：

\[ a=2 \]

验证：\(a=2\) 时三边为 \(2,3,4\)。检查三角形不等式：\(2+3=5>4\) ✓；检查钝角：\(4^{2}=16>2^{2}+3^{2}=13\) ✓

\[ \boxed{\ \text{存在，}a=2\ } \]
提分要点
  • "钝角三角形"的判定用最大边：只要最大边的平方大于另外两边的平方和，就是钝角三角形。不需要真的去算哪个角。
  • 必须先检查三角形存在（\(a+b>c\)），否则解出来的 \(a\) 可能构不成三角形。
  • 本题也可以用海伦公式算面积，但用余弦定理求一个角再算面积更快——因为 \(\sin B\) 可以直接由 \(\cos B\) 得到。
  • 解不等式 \((a-3)(a+1)<0\) 得到 \(-1<a<3\)，再与 \(a\ge2\) 取交集，这一步要写清楚。
真题 10 · 2024 北京卷

在 \(\triangle ABC\) 中，内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)，\(\angle A\) 为钝角，\(a=7\)，\(\sin 2B=\dfrac{\sqrt3}{7}b\cos B\)。

（1）求 \(\angle A\)；

（2）从下列三个条件中选择一个作为已知，使得 \(\triangle ABC\) 存在，求 \(\triangle ABC\) 的面积。

① \(b=7\)；　② \(\cos B=\dfrac{13}{14}\)；　③ \(c\sin A=\dfrac{5\sqrt3}{2}\)。

解析

（1）第一步：化简已知条件。用二倍角公式 \(\sin 2B=2\sin B\cos B\)：

\[ 2\sin B\cos B=\frac{\sqrt3}{7}b\cos B \]

因为 \(\angle A\) 为钝角，所以 \(A>\dfrac{\pi}{2}\)，从而 \(B+C<\dfrac{\pi}{2}\)，故 \(B<\dfrac{\pi}{2}\)，于是 \(\cos B\ne0\)。两边约去 \(\cos B\)：

\[ 2\sin B=\frac{\sqrt3}{7}b \tag{①} \]

第二步：用正弦定理把 \(b\) 换成 \(\sin B\)。由 \(\dfrac{a}{\sin A}=\dfrac{b}{\sin B}\)，得 \(b=\dfrac{a\sin B}{\sin A}=\dfrac{7\sin B}{\sin A}\)。代入①：

\[ 2\sin B=\frac{\sqrt3}{7}\cdot\frac{7\sin B}{\sin A}=\frac{\sqrt3\sin B}{\sin A} \]

因为 \(B\in(0,\pi)\) 所以 \(\sin B>0\)，两边约去 \(\sin B\)：

\[ 2=\frac{\sqrt3}{\sin A} \quad\Longrightarrow\quad \sin A=\frac{\sqrt3}{2} \]

第三步：用"钝角"确定 \(A\)。\(\sin A=\dfrac{\sqrt3}{2}\) 给出 \(A=\dfrac{\pi}{3}\) 或 \(A=\dfrac{2\pi}{3}\)。因为 \(A\) 是钝角（\(A>\dfrac{\pi}{2}\)），所以：

\[ \boxed{\ A=\frac{2\pi}{3}=120^{\circ}\ } \]

（2）条件①：\(b=7\)。

此时 \(a=b=7\)，所以 \(A=B\)。但 \(A=\dfrac{2\pi}{3}\)，于是 \(B=\dfrac{2\pi}{3}\)，两个角之和已经 \(\dfrac{4\pi}{3}>\pi\)，矛盾。

所以条件①不能使三角形存在。

条件②：\(\cos B=\dfrac{13}{14}\)。

第一步：求 \(\sin B\)。因为 \(B<\dfrac{\pi}{2}\)（由 \(A\) 钝角），所以 \(\sin B>0\)：

\[ \sin B=\sqrt{1-\left(\frac{13}{14}\right)^{2}}=\sqrt{\frac{196-169}{196}}=\sqrt{\frac{27}{196}}=\frac{3\sqrt3}{14} \]

第二步：用正弦定理求 \(b\)。

\[ b=\frac{a\sin B}{\sin A}=7\times\frac{\frac{3\sqrt3}{14}}{\frac{\sqrt3}{2}}=7\times\frac{3\sqrt3}{14}\times\frac{2}{\sqrt3}=7\times\frac37=3 \]

第三步：求 \(C\) 和 \(c\)。

\[ C=\pi-A-B=\pi-\frac{2\pi}{3}-B=\frac{\pi}{3}-B \]
\[ \begin{aligned} \sin C &=\sin\left(\frac{\pi}{3}-B\right)=\sin\frac{\pi}{3}\cos B-\cos\frac{\pi}{3}\sin B \\ &=\frac{\sqrt3}{2}\times\frac{13}{14}-\frac12\times\frac{3\sqrt3}{14}=\frac{13\sqrt3}{28}-\frac{3\sqrt3}{28}=\frac{10\sqrt3}{28}=\frac{5\sqrt3}{14} \end{aligned} \]
\[ c=\frac{a\sin C}{\sin A}=7\times\frac{\frac{5\sqrt3}{14}}{\frac{\sqrt3}{2}}=7\times\frac{5\sqrt3}{14}\times\frac{2}{\sqrt3}=7\times\frac57=5 \]

第四步：求面积。

\[ S=\frac12 ab\sin C=\frac12\times7\times3\times\frac{5\sqrt3}{14}=\frac{21}{2}\times\frac{5\sqrt3}{14}=\frac{105\sqrt3}{28}=\frac{15\sqrt3}{4} \]

所以条件②给出 \(\boxed{S=\dfrac{15\sqrt3}{4}}\)。

条件③：\(c\sin A=\dfrac{5\sqrt3}{2}\)。

第一步：求 \(c\)。因为 \(\sin A=\dfrac{\sqrt3}{2}\)：

\[ c\cdot\frac{\sqrt3}{2}=\frac{5\sqrt3}{2} \quad\Longrightarrow\quad c=5 \]

第二步：求 \(b\) 和 \(B\)。由正弦定理 \(\dfrac{b}{\sin B}=\dfrac{c}{\sin C}\)，而 \(\dfrac{a}{\sin A}=\dfrac{7}{\frac{\sqrt3}{2}}=\dfrac{14}{\sqrt3}\)。

所以 \(\dfrac{b}{\sin B}=\dfrac{14}{\sqrt3}\)，即 \(b=\dfrac{14\sin B}{\sqrt3}\)。

用余弦定理 \(a^2=b^2+c^2-2bc\cos A\)：

\[ 49=b^{2}+25-2\times b\times5\times\left(-\frac12\right)=b^{2}+25+5b \]
\[ b^{2}+5b-24=0 \quad\Longrightarrow\quad (b+8)(b-3)=0 \quad\Longrightarrow\quad b=3 \]

（因为 \(b>0\)，舍去 \(b=-8\)。）

这与条件②的结果一致（\(b=3\)、\(c=5\)）。所以面积也是

\[ \boxed{\ S=\frac{15\sqrt3}{4}\ } \]

验算：取 \(a=7\)、\(b=3\)、\(c=5\)，检查 \(A\)：

\[ \cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{9+25-49}{2\times3\times5}=\frac{-15}{30}=-\frac12 \quad\Longrightarrow\quad A=\frac{2\pi}{3}\ \checkmark \]

三边 \(3,5,7\) 满足三角形不等式（\(3+5=8>7\)）✓

提分要点
  • 看到 \(\sin 2B\) 与 \(\cos B\) 同时出现，先约去 \(\cos B\)（但要说明 \(\cos B\ne0\)）。这是本题的关键动作。
  • "\(\angle A\) 为钝角"这个条件用了两次：第一次用于说明 \(\cos B\ne0\)（因为 \(B<\dfrac{\pi}{2}\)），第二次用于从 \(\sin A=\dfrac{\sqrt3}{2}\) 的两个解中选出 \(A=\dfrac{2\pi}{3}\)。
  • 结构不良题的判断方法：把条件代入，看是否与已知矛盾。本题条件①导致 \(A=B\)，与 \(A\) 钝角矛盾，所以三角形不存在。
  • 条件②和③虽然形式不同，但解出的三边相同（\(3,5,7\)），所以面积相同。这说明出题人设计了两个等价条件。
  • 用余弦定理列方程解 \(b\) 时，注意 \(\cos A=-\dfrac12\) 是负数，"减负得正"。
真题 11 · 2020 新高考I卷（结构不良题）

在条件 ① \(ac=\sqrt3\)，② \(c\sin A=3\)，③ \(c=\sqrt3\,b\) 这三个条件中任选一个，补充在下面问题中。若问题中的三角形存在，求 \(c\) 的值；若问题中的三角形不存在，说明理由。

问题：是否存在 \(\triangle ABC\)，它的内角 \(A\)、\(B\)、\(C\) 的对边分别为 \(a\)、\(b\)、\(c\)，且 \(\sin A=\sqrt3\sin B\)，\(C=\dfrac{\pi}{6}\)，______？

解析

共同的第一步：把公共条件翻译出来。

由 \(\sin A=\sqrt3\sin B\)，用正弦定理（\(a=2R\sin A\)、\(b=2R\sin B\)）：

\[ a=\sqrt3\,b \tag{甲} \]

又 \(C=\dfrac{\pi}{6}\)，所以 \(A+B=\pi-\dfrac{\pi}{6}=\dfrac{5\pi}{6}\)，且 \(\sin C=\dfrac12\)。

再求 \(A\) 和 \(B\) 的具体值（这是关键准备）。由 \(\sin A=\sqrt3\sin B\) 且 \(A+B=\dfrac{5\pi}{6}\)，得 \(A=\dfrac{5\pi}{6}-B\)：

\[ \sin\left(\frac{5\pi}{6}-B\right)=\sqrt3\sin B \]
\[ \sin\frac{5\pi}{6}\cos B-\cos\frac{5\pi}{6}\sin B=\sqrt3\sin B \]
\[ \frac12\cos B+\frac{\sqrt3}{2}\sin B=\sqrt3\sin B \]
\[ \frac12\cos B=\frac{\sqrt3}{2}\sin B \quad\Longrightarrow\quad \tan B=\frac{1}{\sqrt3}=\frac{\sqrt3}{3} \]

因为 \(B\in\left(0,\dfrac{5\pi}{6}\right)\)，所以 \(B=\dfrac{\pi}{6}\)，于是：

\[ A=\frac{5\pi}{6}-\frac{\pi}{6}=\frac{2\pi}{3} \]

所以公共条件确定了一个形状固定的三角形：\(A=\dfrac{2\pi}{3}\)、\(B=C=\dfrac{\pi}{6}\)，即等腰三角形（\(b=c\)）。

选条件①：\(ac=\sqrt3\)。

由正弦定理 \(\dfrac{a}{\sin A}=\dfrac{c}{\sin C}\)，得：

\[ a=c\cdot\frac{\sin A}{\sin C}=c\cdot\frac{\frac{\sqrt3}{2}}{\frac12}=\sqrt3\,c \]

代入 \(ac=\sqrt3\)：

\[ \sqrt3\,c\cdot c=\sqrt3 \quad\Longrightarrow\quad c^{2}=1 \quad\Longrightarrow\quad c=1 \]

（\(c>0\)，舍去负根。）

检验：\(c=1\)、\(a=\sqrt3\)、\(b=\dfrac{a}{\sqrt3}=1\)。所以 \(b=c=1\) ✓ 符合 \(B=C\)。

\[ \boxed{\ \text{三角形存在，}c=1\ } \]

选条件②：\(c\sin A=3\)。

由 \(a=\sqrt3\,c\)（上面已得），再用正弦定理 \(c=a\cdot\dfrac{\sin C}{\sin A}=a\cdot\dfrac{\frac12}{\frac{\sqrt3}{2}}=\dfrac{a}{\sqrt3}\)，与 \(a=\sqrt3c\) 一致 ✓

由 \(c\sin A=3\)，即 \(c\cdot\dfrac{\sqrt3}{2}=3\)：

\[ c=\frac{3}{\frac{\sqrt3}{2}}=\frac{6}{\sqrt3}=2\sqrt3 \]

检验：\(c=2\sqrt3\)、\(a=\sqrt3\times2\sqrt3=6\)、\(b=\dfrac{a}{\sqrt3}=\dfrac{6}{\sqrt3}=2\sqrt3\)。所以 \(b=c=2\sqrt3\) ✓

再验证 \(c\sin A=2\sqrt3\times\dfrac{\sqrt3}{2}=3\) ✓

\[ \boxed{\ \text{三角形存在，}c=2\sqrt3\ } \]

选条件③：\(c=\sqrt3\,b\)。

由正弦定理 \(\dfrac{c}{b}=\dfrac{\sin C}{\sin B}\)：

\[ \frac{c}{b}=\frac{\sin C}{\sin B}=\frac{\frac12}{\sin B}=\frac{1}{2\sin B} \]

已知 \(c=\sqrt3\,b\)，即 \(\dfrac cb=\sqrt3\)，所以：

\[ \sqrt3=\frac{1}{2\sin B} \quad\Longrightarrow\quad \sin B=\frac{1}{2\sqrt3}=\frac{\sqrt3}{6} \]

但前面已经算出 \(B=\dfrac{\pi}{6}\)，此时 \(\sin B=\dfrac12\)。两者矛盾（\(\dfrac{\sqrt3}{6}\approx0.289\ne\dfrac12=0.5\)）。

换一个角度验证：由公共条件 \(b=c\)（因为 \(B=C\)），而条件③要求 \(c=\sqrt3\,b\)，即 \(b=\sqrt3 b\)，得 \(b=0\)，与 \(b>0\) 矛盾。

\[ \boxed{\ \text{三角形不存在}\ } \]
提分要点
  • 结构不良题的解法：先把"公共条件"完全解出来，再逐个代入选项。本题的公共条件已经确定三角形形状（\(A=\dfrac{2\pi}{3}\)，\(B=C=\dfrac{\pi}{6}\)，即 \(b=c\)），所以三个选项的判断都很快。
  • 判断"三角形不存在"最简洁的方法：找矛盾。本题条件③要求 \(c=\sqrt3b\)，但公共条件已经推出 \(b=c\)，两者矛盾。
  • 求 \(A\)、\(B\) 时用"和角公式展开 \(\sin\left(\dfrac{5\pi}{6}-B\right)\)"，再用 \(\tan B\) 求出 \(B\)。这是"已知两边角关系求角"的标准手法。
  • 选完条件后要"检验"，确认解出的边长确实满足所有条件（包括三角形不等式）。
  • 三个选项中，①②都能算出确定的 \(c\)，③矛盾。这类题目的设计通常如此——有一个"陷阱选项"。

8.5　提分要点总结

十年真题告诉我们的五件事
  1. 解三角形是绝对主流，必须拿满。十年里三角函数大题几乎都是解三角形。核心工具只有两个：正弦定理（边角互化）和余弦定理（已知三边或两边夹角）。
  2. "由等式求角"的两条路：统一成角，或统一成边。等式里全是 \(\sin\)、\(\cos\) 就统一成角（用正弦定理）；等式里有平方项和 \(\cos\) 就统一成边（用余弦定理）。真题 3、4、7、8 都用到了这个判断。
  3. 求范围/最值的关键是"用一个角表示所有量"。把边都换成角，或者把角都换成一个角，再求这个角的范围。本题型的失分点几乎全在"角的范围没找全"。
  4. "锐角三角形""钝角三角形"必须翻译成不等式。锐角三角形：三个角都小于 \(\dfrac{\pi}{2}\)（真题 3、8）；钝角三角形：最大边的平方大于另外两边平方和（真题 9）。这一步直接决定答案端点的开闭。
  5. 新高考的结构不良题要"先解公共条件，再逐项代入"。真题 10、11 都是这种题型。判断"不存在"的最快方法是找矛盾（如与已知角冲突、与三角形不等式冲突）。
考场时间分配建议
  • 解三角形大题：限时 10 分钟，目标满分。第一问 3~4 分钟（求角），第二问 5~6 分钟（求边/面积/范围）。
  • 恒等变换 + 图象题：限时 10 分钟。化简占一半时间，求性质占一半。化简不出来，后面全错，所以这一步要慢一点、检查一遍。
  • 求范围题的"保分动作"：先把目标量用一个角表示出来（这一步有分），再写这个角的范围（这一步也有分），最后才是求最值。
  • 验算技巧：把解出的边长代回余弦定理，算一遍已知角的余弦值，看是否与题目给出的一致。这 30 秒能救回整道题。
  • 常用特殊值要背熟：\(\sin 75^\circ=\dfrac{\sqrt6+\sqrt2}{4}\)、\(\sin 15^\circ=\dfrac{\sqrt6-\sqrt2}{4}\)、\(\tan 15^\circ=2-\sqrt3\)。
